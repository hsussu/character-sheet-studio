# 角色设定集工坊

## 五条铁律

| # | 铁律 | 原因 |
|---|---|---|
| 1 | **全身主视觉 + 正/侧/背三视图：锁死必出** | 这是整套的地基，缺了不成设定集 |
| 2 | **其余区块选 3–6 个** | 少于 3 显空，多于 6 必糊 |
| 3 | **单张图元素 ≤ 12 个** | 超了必糊：小图崩、肢体融合、面部漂移 |
| 4 | **版式用百分比坐标，不用形容词** | 「优雅的不对称」模型理解不了 |
| 5 | **角色锁定卡未确认，不进入生成** | 之后每张图复用这份卡，错了全重做 |

## 版式骨架

成品是一整版，不是一堆散图。标准骨架：

```text
左 38%：主视觉全身（最大，唯一的大图）
右 60%：多角度立绘 3 格 → 头部细节 → 服装细节 → 标志物组
下半：属性表、表情、姿态、色卡材质
```

坐标、逐格拆解、三种风格模板见 [references/sheet-layouts.md](references/sheet-layouts.md)。

**生成按区块分开出图，最后用 HTML 拼成一版**，不要指望模型一次画完。

## 元素配额

| 区块 | 状态 | 格数 |
|---|---|---|
| 主视觉全身 | **锁死** | 1 张大图 |
| 多角度立绘（正面/侧面/背面，方向固定） | **锁死** | 3 格 |
| 头部细节 | 可选 | 1–5 格（脸 / 眼 / 眉 / 发 / 鼻唇耳） |
| 服装细节 | 可选 | 1–5 格（领口 / 袖口 / 腰 / 面料 / 鞋） |
| 标志物组（配饰 / 道具 / 武器，三选一） | 可选（强推） | 3–5 格 |
| 表情 | 可选（强推） | 4–6 格 |
| 姿态 | 可选 | 3–5 格（坐 / 倾 / 蹲 / 俯视 / 仰视） |
| 色卡 + 材质板 | 可选 | 2 个区块 |
| 属性表 / 标语 | 可选 | 后期排版，不占生成图 |

除两个锁死项，在可选区选 **3–6 个区块**。

### 三档套餐（拿不准时直接用）

| 套餐 | 区块数 | 组合 | 适合 |
|---|---|---|---|
| 轻量 | 3 | 头部细节 + 服装细节 + 标志物 | 只想快速看效果 |
| 标准 | 4 | 上述三项 + 表情 | 日常用，最常见 |
| 完整 | 6 | 上述四项 + 姿态 + 色卡材质 | 要拿去喂 AI / 做视频参考 |

选完告诉用户：「当前 4 个区块，还想加姿态或色卡吗？」——**允许继续添加，但总数不许超 6**。

## 工作流

### 阶段 0 · 参考图解析

输出解析表，不要急着生成。

| 解析项 | 填什么 |
|---|---|
| 版式家族 | Grid Model Sheet / Identity Board / Poster / Detail Sheet |
| 区块清点 | 有哪些区块、各几格、总元素数 |
| 风格模板 | A 新中式仙侠 / B 都市清冷 / C 哥特暗黑 / 自定 |
| 风格继承五项 | 背景明度、主色三色、装饰元素、光的性格、材质复杂度 |
| 角色归属 | 图里就是要的角色 / 只是风格样板 / 只改配色发型 |

风格继承五项必须逐项填，见 [references/sheet-layouts.md](references/sheet-layouts.md) 第四节。

### 阶段 1 · 模板定型

输出区块清单给用户点头：

```text
锁死：主视觉全身（张1）+ 正/侧/背三视图（张2）
可选①：头部细节 4 格
可选②：服装细节 4 格
可选③：标志物组 5 格（待定：配饰 / 道具 / 武器）
可选④：表情 6 格
```

每张给百分比坐标；每张元素 ≤ 6 格。

### 阶段 2 · 角色访谈

**每轮不超过 5 个问题。** 完整问题清单见 [references/interview-questions.md](references/interview-questions.md)。

四轮骨架：身份与世界观 → 长相 → 服装材质与标志物类别 → 性格表情与区块组合。

**必问的一条**（每做一个新角色都要问，不许跳过）：

> 这个角色的标志物属于哪一类——**配饰 / 道具 / 武器**？

- **配饰**：耳饰、项链、墨镜、手袋、腰带、戒指（图 2 林雾的类型）
- **道具**：随身器物、工具、机关、书本、乐器、科技小件（图 1 月沐晞的类型）
- **武器**：剑、匕首、枪械、法杖、弓（战斗向角色的类型）

用户选完，那一组区块就按该类别出，命名也改成「配饰与专属物 / 道具与随身物 / 武器与战具」，不要混装。

访谈规则：

- 参考图里已有角色：只问「哪些要改」，其余从图提取。
- 用户说「你定」：自己定并给依据，不许空着。
- 回答抽象：追问一次落到可画的具体项。

### 阶段 3 · 角色锁定卡

```text
【人物】名字 / 性别 / 年龄 / 身份 / 世界观
【脸】脸型 + 眉眼形状 + 唇形 + 特殊标记（虎牙/泪痣/耳饰）
【发】长度 + 直卷 + 刘海 + 束发方式
【衣】主色 + 款式 + 3 个结构特征
【体型】身高体重 + 比例 + 默认站姿重心
【标志物】类别（配饰/道具/武器）+ 1–3 件具体物，含材质与颜色
【风格】继承参考图的五项（背景明度/主色/装饰/光/材质复杂度）
```

确认后才生成；改哪条只改哪条。

### 阶段 4 · 分步生成

按区块推进，前一步点头才进下一步。

| 步 | 生成内容 | 检查点 |
|---|---|---|
| 1 | 主视觉全身单张（不带格子） | 脸、气质、服装结构 |
| 2 | 三视图：正 / 侧 / 背 | 三张是同一人？发型腰带一致？ |
| 3 | 头部细节组 | 眼型、发型轮廓、虎牙等标记有没有丢 |
| 4 | 服装细节组 | 领口、袖口、腰、面料纹理是否清晰 |
| 5 | 标志物组（按选定类别） | 数量、材质、发光点 |
| 6 | 表情组 | 表情跨度够不够 |
| 7 | 姿态组（如选） | 重心、手、衣褶 |
| 8 | 色卡 + 材质板（如选） | 主色是否与图一致 |

生成全部按区块出图，最后统一进阶段 5 拼版。

提示词从 [references/prompt-template.md](references/prompt-template.md) 的区块模板填，角色段从锁定卡原样粘贴。

**改图规则**：用户说「脸太圆」「衣服不像」，只改对应那一维度重生成，不要重写整段提示词。

### 阶段 5 · 组装交付

- 用单文件 HTML 还原参考图整版：左大图 + 右格栅 + 文字区。
- 同时交付 PNG/JPG 成品。
- 命名：`角色名-设定集.png`，改版加 `-1`、`-2`。

## 生成工具与额度

| 环节 | 用什么 |
|---|---|
| 全新角色、无参考图 | `image_gen` 文生图 |
| 已有角色图、必须保脸 | `image_edit` 或带参考图的生成 |
| 多张研究图 | 逐张排队，一张一个请求，便于单独返工 |

**额度规则**：每步生成前先说这一步出几张图、大概消耗多少，等用户点头再发请求。不许闷头连刷。

## 五维度提示词骨架

每段提示词必须覆盖：

1. **内容** — 角色本体（脸、发、衣、标志物）
2. **场景与风格参考** — 版式类型 + 风格锚点（照参考图模板选，不自创）
3. **色调色彩** — 主色三色 + 点缀 + 明度 + 打光
4. **构图视角** — 画幅 + 百分比坐标 + 朝向与镜头高度
5. **细节补充** — 材质、金属、纹样、清晰度

## 失败模式速查

| 症状 | 原因 | 修法 |
|---|---|---|
| 小图全糊、脸都不一样 | 元素超 12 | 拆区块，一张一区块 |
| 每张都变脸 | 只靠文字说 same face | 参考图权重拉高（MJ `--ow 300~400`，默认即 400；IP-Adapter 0.6~0.8） |
| 排版乱 | 用了形容词 | 换百分比坐标 |
| 浅色衣在白底没轮廓 | 背景太纯 | 背景 2% 灰 + 极淡落地投影 |
| 图上文字乱码 | 模型写不了中文 | 留白，后期 HTML 加字 |
| 越写「不要」越出现 | 否定句不敏感 | 挪进 negative prompt |
| 多视角像连环画 | 缺独立研究约束 | 加「每个视角独立完成、互不遮挡、无场景连贯性」 |
| 区块堆太多、整版挤 | 超过 6 个可选区块 | 砍到 6 个以内，次要项交给后期 |
| 风格跑偏成别的画风 | 没继承参考图五项 | 回阶段 0 重填风格继承 |

## 交付前自检

- [ ] 主视觉全身 + 正/侧/背三视图都在
- [ ] 三视图方向就是正/侧/背，没换成别的角度
- [ ] 可选区块 3–6 个，不多不少
- [ ] 标志物类别（配饰/道具/武器）已问过并确认
- [ ] 风格继承五项填了，没自创风格
- [ ] 锁定卡 7 条都有具象值，无「好看」「高级」这类空词
- [ ] 每张图 ≤ 6 格，且整张元素 ≤ 12
- [ ] 文字区是留白
