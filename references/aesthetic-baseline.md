# 最低审美基准（Aesthetic Baseline）

> 任何一张图、任何一版成品，**低于这套基准就不许交付**。
> 这不是「追求更好」，而是「不许更差」的底线。达不到就重出，不许解释、不许找理由。

一句话概括：**脸要干净、色要亮、衣要利落、细节要经得起放大。**

---

## 一、七道闸门（逐道过，过不了不许进下一道）

| # | 闸门 | 一句话判据 | 不合格长什么样 |
|---|---|---|---|
| 1 | **脸** | 裸妆、清透、干净、有胶原感 | 浓妆、艳唇、彩色眼影、油光、法令纹、男性化骨相 |
| 2 | **色** | 整体中高明度，主色浅、点缀才艳 | 全身深色、紫到发黑、满身金、一片同色 |
| 3 | **廓形** | 上短下长、腰线明确、剪裁合体 | 罩一件大袍、长披风拖地、胸衣外穿、廓形糊成一坨 |
| 4 | **丰富度** | 配饰 6–8 件，四区分布，每件能放大 | 只有一件外套＋一个挂件，空、像纸片人 |
| 5 | **精度** | 至少 4 处细节可放大到 1:1 不糊 | 金属是一块灰斑、发丝成片、织物没纹理 |
| 6 | **武器道具** | 可拆解 ≥3 段、握持正确、与属性同源 | 一根无结构的发光棒、手穿模、刀和角色没关系 |
| 7 | **版式** | 主视觉最大、无框无投影、留白分区 | 满版卡片白框、主视觉缩成小图、表格感 |

七道全过才算「达标」。任一道不过，整张重出，不做局部修补式自我安慰。

## 二、闸门 1 · 脸（最狠的一道）

脸是观众第一眼判生死的地方。**宁可画得素，不许画得浓。**

### 妆感数值（硬指标）

| 项 | 要求 | 禁止 |
|---|---|---|
| 唇 | 浅玫瑰 / 豆沙 / 自然血色；饱和度低、边缘柔；可有一点点水光 | 艳红、玫红、紫黑唇、亮面厚涂、勾死唇线、咬唇妆 |
| 眼影 | 不画。最多用比肤色深 1 个明度档的同色做眼窝过渡 | 紫／红／亮片眼影、彩色眼线、下眼影重涂 |
| 眼线 | 可以不画；画就贴睫毛根、尾端不长于 3mm | 上挑长尾、猫眼、晕开的脏眼线 |
| 睫毛 | 自然、根根、长度中等 | 浓密假睫毛、整齐扇面 |
| 腮红 | 只在颧骨上方一小块，透明度 10%–30%，面积 ≤ 面颊 1/3 | 猴屁股、横跨鼻梁、橘红大块、血痕感 |
| 眉 | 自然毛流、有毛尖、眉尾细 | 硬边、上下两条平行线、过粗过黑 |
| 皮肤 | 白／冷白但通透，可见次表面散射与极细毛孔 | 蜡像塑料感、油光高光面积大、磨皮成一片 |

### 骨相与年龄感

- 脸型：小鹅蛋 / 瓜子，下颌收窄但**保留一点软组织**，下巴不过尖、不过方。
- 年轻人的脸＝**胶原感在**：面颊饱满、颧骨不突出、无鼻唇沟、无颧下阴影、无颈纹、无眼袋。
- 眼睛：清澈有神，双眼皮干净，虹膜分层，视线平视或轻微偏转；**不眯、不吊、不压**。
- 鼻：小巧、鼻头圆润。
- 神情：靠**微表情**说话（唇角 5°、眼神一点笑意、眉梢松），不靠五官夸张。

### 脸的红线（触发任一，整张作废）

- 浓妆 / 艳色唇 / 彩色眼影
- 表情凶、像反派、压眉瞪人
- 男性化骨相（粗眉、方下巴、平胸刻意处理）
- 脸像另一个人（换脸、脸崩、双眼距失衡）
- 五官比例失真（眼过大、下巴过尖、头身比失调）

> 记忆锚点：**要「淡而干净」，不要「浓而艳」。** 干净的脸才显年轻，浓妆的脸只会显老、显妖。

## 三、闸门 2 · 色

| 项 | 要求 |
|---|---|
| 明度 | 整体中高明度。背景明度 ≥ 90%（浅灰白 `#F0F1F3` / `#EDEEF2` 一类）；角色亮部占画面 ≥ 45% |
| 深色面积 | ≤ 40%。深色只能用来勾轮廓和压层次，不许铺满身 |
| 颜色数量 | ≤ 5 个（含金属色与发光的点缀色） |
| 配比 | 主色 60% ± 5 / 辅色 30% ± 5 / 点缀 10% |
| 饱和度 | 主色与辅色低饱和（高级灰调）；**只有点缀允许高饱和**（ luminous 发光、雷光、宝石） |
| 金属 | 银 / 钢为主；铜金只做小面积点缀，≤ 5% |
| 冷暖 | 冷色主体 + 一点点暖色点缀；或反过来。**不许整体冷暖不分、糊成灰** |

**色彩翻车清单**：紫压到发黑、全身同一个深色、荧光色大面积、全身金、上衣与下装明度完全一样。

## 四、闸门 3 · 廓形与剪裁

| 项 | 要求 | 为什么 |
|---|---|---|
| 腰线 | **必须明确**（腰带 / 收腰 / 高腰下装三选一） | 没有腰线＝一块布，显胖显老 |
| 比例 | **上短下长**：上衣不盖过胯，下装提腰 | 这是「年轻利落」的根 |
| 外层长度 | 长物只能是**半透纱 / 披挂 / 后裾**，且重量轻、透光；**禁止厚重长袍、厚披风** | 大袍＝土、老气、压死廓形 |
| 剪裁 | 肩线、袖型、裤型可命名（落肩 / 立领 / 束脚 / 直筒） | 说不清就是糊 |
| 露肤 | **只走一处**（腰 / 肩颈 / 腿，三选一最多三选二） | 三处全露＝廉价 |
| 胸衣 | 内层必须是**完整上衣**（高领打底 / 背心 / 斜襟上衣），**禁止内衣外穿感** | 「护胸背心」这种写法会被画成胸罩外穿 |

### 层次（与 SKILL.md 的强制清单同步）

三层可辨 + 三种材质 + 三处边缘露出 + 配饰密度（上身 ≥3 / 腰 ≥2 / 腿 ≥1）。
三层必须是**穿的关系**（内搭在里面、外套在外面），不是三件并排挂着。

## 五、闸门 4 · 丰富度

| 项 | 要求 |
|---|---|
| 配饰件数 | 6–8 件（少于 6 件＝空） |
| 分区 | 上身 / 腰部 / 腿部 / 手部四个区都要有东西 |
| 母题 | 一个符号重复 ≥3 处（同一扣件、同一雷纹、同一色点） |
| 功能件 | ≥2 件是「看起来能用的」（挂钩、扣具、绑带、容器、插槽） |
| 可放大 | 每件配饰单独放大后依然有结构、有材质、有光 |

## 六、闸门 5 · 精度

至少这 4 处，放大到 1:1 依然站得住：

1. **眼睛**——虹膜分层、高光、睫毛根根、内眼角
2. **发丝**——分层、有透光、有各向异性高光、发梢不糊成块
3. **金属件**——哑光底 + 硬高光 + 少量划痕/旧化，边缘有厚度
4. **织物**——能看出是什么布（针织颗粒 / 机能布斜纹 / 纱的通透 / 皮革的折痕）

再加两处加分项：缝线拉链扣眼可见、手部五指结构准确不穿模。

### 脸部检查点（分档验，A 档默认）

**A 档 · 二次元半写实 2.5D（默认档）**：脸不塌不糊；赛璐璐阴影分色干净（明暗交界利落，阴影不脏不灰）；发丝分组一眼数得清；布料与金属有材质区分。四条有两条不过＝A 尾缀没吃进去，重写再出。

**B 档 · 高精度 3D 半写实（仅在用户点名 3D 时启用的下档）**：

| # | 检查点 | 不达标的样子 |
|---|---|---|
| 1 | **眼窝有凹陷**（靠结构，不是靠眼影画出来的） | 眼睛平贴脸上、像贴纸 |
| 2 | **鼻梁有真实明暗转折**（鼻根、鼻背、鼻头三段） | 鼻子是一块平色 |
| 3 | **皮肤有极细毛孔且不油亮**（哑光、低反射） | 塑料光亮、或纯平色块无质感 |

三条缺两条＝B 尾缀没吃进去，重写提示词再出，不许交付。

**B+ 档 · CG 级（参考图是游戏 CG / 精修 AI 片时）**：在上面三条之外再加三条——①皮肤有次表面散射（耳廓/鼻翼/下颌逆光透红）②眼睛有角膜双高光 + 虹膜三层 ③发丝成束（每束 3–8 根、束间有空隙）且发梢透光。三条缺两条＝只是普通 B 档，不是 CG 级。参数全文见 `face-cg.md`，档位分辨见 `render-grade.md`。

**C 档 · BJD**：**默认不做**。只有用户点名「BJD / 球关节 / 树脂娃」才切，且必须画出外露球关节、哑光树脂皮肤、玻璃球眼——做了 CG 脸挂 BJD 名是两头不靠。

**两档通用的对冲**：半写实容易把脸画平、画萌；3D 档则容易推向成熟偏冷。要「忧郁但好看、带肉感」时，内容段必须补：颧骨略软下巴圆滑（不瘦骨）、唇色极淡但边缘柔有一点点水光、眼型细长内眼角微低（不吊眼不大眼）。

## 七、闸门 6 · 武器 / 道具

| 项 | 要求 |
|---|---|
| 可拆解 | ≥3 段可命名（如：刃部 / 护手 / 握柄 / 能量核 / 铭文） |
| 与属性同源 | 角色的能力要长在武器上（雷系 → 雷核、导线、雷纹、放电口） |
| 握持 | 手与柄贴合、不穿模、姿势合理，能说清是反握还是正握 |
| 比例 | 武器长度与身高匹配（长刀约身高的 0.55–0.7，短刃 0.3–0.4） |
| 与服装统一 | 武器材质/金属色/发光色，必须复用服装的辅色或点缀色 |

## 八、闸门 7 · 版式（见 layout-rules.md，此处只列底线）

- 主视觉宽 ≥ 40%、高 ≥ 版面 55%，全版最大。
- 图片不加卡片边框、不加白底、不加投影，靠 24–30px 留白分区。
- 一律 `object-fit: contain`。
- 属性表低对比（浅灰底或纯文字）。
- 每区块挂编号 + 中文标题 + 英文小字。
- 信息分区：6–9 个（主视觉 / 信息栏 / 面部特写 / 三视图 / 服装拆解 / 细节展示 / 武器设定 / 配色卡 / 表情或氛围图）。

## 九、年轻感 vs 老气感（判据表）

用户原话：「就像年轻人和老年人的区别」。判定按这张表：

| 维度 | 年轻（对） | 老气（错） |
|---|---|---|
| 明度 | 亮、浅、透气 | 暗、沉、发黑 |
| 廓形 | 上短下长、腰线利落 | 长袍、披风、罩衫、拖地 |
| 材质 | 哑光布＋半透纱＋少量金属 | 全厚呢、全皮革、堆金 |
| 妆 | 裸妆、素、干净 | 浓妆、艳唇、亮片 |
| 配饰 | 少而精、每件有结构 | 多而杂、堆成杂货铺 |
| 露肤 | 一处，节制 | 三处全露 或 一点都不露 |
| 元素 | 一个母题贯穿 | 元素各说各话 |

## 十二、五张对标模板提炼的锚点（看到这些长相就是对的）

| 模板 | 学到什么 |
|---|---|
| **颜歌·霜刃骑士** | 脸极干净（裸妆、几乎无腮红）；黑+蓝+银三色；高腰短裤＋长腿套＋厚底靴，廓形利落；薄纱披挂是半透的，不压身 |
| **云行锦途** | 主色白+浅蓝；机能束具式短上衣＋工装裤；厚底机能靴；配色卡与款式结构图并列；纹样当母题贯穿 |
| **紫黑机能（男）** | 低饱和紫灰调；脸冷白清透；层次＝T恤＋卫衣＋夹克＋工装裤；配饰 8 件且各有特写；破损工艺当质感卖点 |
| **星河幻音** | 紫蓝＋星形母题重复到底；短上衣露腰一处；多层短裙＋厚底鞋；版式＝角色资料卡＋三视图＋细节六格 |
| **月沐晞** | 新中式轻机械；脸干净带笑意有虎牙；分区＝多角度立绘／头部细节／服装细节／配饰道具／表情姿态；银色当统一金属 |

五张的共同点只有一句：**脸素、色亮、衣短、件精、细节能放大。**

## 十三、交付前验收（逐条打勾，缺一项不许交付）

- [ ] 脸是裸妆：唇浅、无眼影、腮红淡（≤30%）
- [ ] 脸不凶、不妖、不男性化，有胶原感
- [ ] 背景明度 ≥90%，深色面积 ≤40%
- [ ] 主色 60 / 辅色 30 / 点缀 10，颜色 ≤5 个
- [ ] 有明确腰线，上短下长，无厚重长袍
- [ ] 内层是完整上衣，无内衣外穿感
- [ ] 三层可辨（穿的关系）、三材质、三处边缘露出
- [ ] 配饰 6–8 件，四区分布，母题 ≥3 处，功能件 ≥2
- [ ] 4 处细节（眼/发/金属/织物）可放大不糊
- [ ] 武器 ≥3 段可拆解，握持正确，与属性同源
- [ ] 版式：主视觉 ≥40%、无框、contain、属性表低对比
- [ ] 已挂**一条**风格尾缀（默认 A·2.5D，用户点名 3D 才换 B）＋「统一负面词库」
