# 角色设定集工坊 V5

从「设定图 / 一句话描述」产出**角色设定集资料卡**（左主视觉 + 右五栏）或**资产图**（A-pose 透明底分块 PNG）。

## V5 的三处硬核补强

| 模块 | 解决什么 | 文件 |
|---|---|---|
| 主视觉底图工程 | 抠图换底后脚悬空、拿模糊原图当底导致"周围糊" | `references/hero-plate.md` |
| 颗粒治理 | 背景纸纹/噪点被放大，后期平滑无效，只能换底 | `references/noise-control.md` |
| HUD 资料卡骨架 | 编号块 + 刻度线 + 卡片属性表 + 图格细边，一步出图 | `references/card-layout-hud.md`、`assets/card-skeleton-hud.html`、`scripts/build_card.py` |

另有 `references/field-notes.md`：用户怎么提需求、容易误读的词（"双持"= 一把剑双手握）、幼态脸判据、开工前核对清单。

## 一条命令出卡

```bash
python3 scripts/build_card.py config.json
```

`config.json` 里给图片路径、文案、色值（强调色跟角色主色走），脚本替换占位符并用 Playwright 渲染（1440 CSS 宽 × device_scale_factor 1.5 → 2160×2570 左右）。

## 十条铁律（摘要）

1. 左主视觉、右三视，位置锁死
2. 五栏固定填满：三视图 3 / 头部 5 / 服装 5 / 配饰 1–5 / 表情 6，**无姿态区块**
3. 单次请求 ≤6 格、≤12 主体物件
4. 坐标用百分比，背景用色值
5. 必停三次：角色档案 → 风格议案 → 地基确认
6. 服装 ≥3 层叠穿、≥3 材质、≥3 处边缘露出
7. 风格尾缀二选一，默认 2.5D
8. 不得低于《最低审美基准》七道闸门
9. **开局先核对上一步定稿**（腰挂/剑手/腿环/发色分界）
10. **底图必须有地平面，颗粒必须换底根治**
