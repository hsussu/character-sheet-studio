# 最低审美基准（Aesthetic Baseline）

> 任何一张图、任何一版成品，**低于这套基准就不许交付**。
> 这不是「追求更好」，而是「不许更差」的底线。达不到就重出，不许解释、不许找理由。

一句话概括：**脸要干净、色要亮、衣要利落、细节要经得起放大。**

---

## 一、七道闸门（逐道过，过不了不许进下一道）

| # | 闸门 | 一句话判据 | 不合格长什么样 |
|---|---|---|---|
| 1 | **脸** | 裸妆、清透、干净、有胶原感 | 浓妆、艳唇、彩色眼影、油光、法令纹、男性化骨相 |
| 2 | **色** | 整体中高明度，主色浅、点缀才艳 | 全身深色、紫到发黑、满身金、一片同色 |
| 3 | **廓形** | 上短下长、腰线明确、剪裁合体 | 罩一件大袍、长披风拖地、胸衣外穿、廓形糊成一坨 |
| 4 | **丰富度** | 配饰 6–8 件，四区分布，每件能放大 | 只有一件外套＋一个挂件，空、像纸片人 |
| 5 | **精度** | 至少 4 处细节可放大到 1:1 不糊 | 金属是一块灰斑、发丝成片、织物没纹理 |
| 6 | **武器道具** | 可拆解 ≥3 段、握持正确、与属性同源 | 一根无结构的发光棒、手穿模、刀和角色没关系 |
| 7 | **版式** | 主视觉最大、格内 1px 边 + 留白分区 | 满版卡片白框、主视觉缩成小图、表格感 |

七道全过才算「达标」。任一道不过，整张重出，不做局部修补式自我安慰。

## 二、闸门 1 · 脸（最狠的一道）

脸是观众第一眼判生死的地方。**宁可画得素，不许画得浓。**

### 妆感数值（硬指标）

| 项 | 要求 | 禁止 |
|---|---|---|
| 唇 | 浅玫瑰 / 豆沙 / 自然血色；饱和度低、边缘柔 | 艳红、玫红、紫黑唇、亮面厚涂、勾死唇线 |
| 眼影 | 不画。最多用比肤色深 1 个明度档的同色过渡 | 紫／红／亮片眼影、彩色眼线 |
| 眼线 | 可以不画；画就贴睫毛根、尾端不长于 3mm | 上挑长尾、猫眼、晕开的脏眼线 |
| 睫毛 | 自然、根根、长度中等 | 浓密假睫毛、整齐扇面 |
| 腮红 | 颧骨上方一小块，透明度 10%–30%，面积 ≤ 面颊 1/3 | 猴腮、横跨鼻梁、橘红大块 |
| 眉 | 自然毛流、有毛尖、眉尾细 | 硬边、上下两条平行线、过粗过黑 |
| 皮肤 | 白／冷白但通透，可见次表面散射与极细毛孔 | 蜡像塑料感、油光高光面积大 |

### 骨相与年龄感

- 脸型：小鹅蛋 / 瓜子，下颌收窄但**保留一点软组织**，下巴不过尖、不过方。
- 年轻人的脸＝**胶原感在**：面颊饱满、颧骨不突出、无鼻唇沟、无颧下阴影、无颈纹、无眼袋。
- 眼睛：清澈有神，双眼皮干净，虹膜分层；**不眯、不吊、不压**。
- 鼻：小巧、鼻头圆润。
- 神情：靠**微表情**说话（唇角 5°、眼神一点笑意），不靠五官夸张。

### 脸的红线（触发任一，整张作废）

- 浓妆 / 艳色唇 / 彩色眼影
- 表情凶、像反派、压眉瞪人
- 男性化骨相（粗眉、方下巴）
- 脸像另一个人（换脸、脸崩、双眼距失衡）
- 五官比例失真（眼过大、下巴过尖、头身比失调）

> 记忆锚点：**要「淡而干净」，不要「浓而艳」。**

**幼态四信号**（出现两个就说明脸做小了）：眼大而圆/虹膜占满眼眶、脸偏圆下巴尖短、腮红面积大且靠苹果肌中间、五官排布靠下额占太多。改法见 `field-notes.md` §三。

## 三、闸门 2 · 色

| 项 | 要求 |
|---|---|
| 明度 | 整体中高明度。背景明度 ≥ 90%；角色亮部占画面 ≥ 45% |
| 深色面积 | ≤ 40%。深色只能用来勾轮廓和压层次 |
| 颜色数量 | ≤ 5 个 |
| 配比 | 主色 60% ± 5 / 辅色 30% ± 5 / 点缀 10% |
| 饱和度 | 主色与辅色低饱和；**只有点缀允许高饱和** |
| 金属 | 银 / 钢为主；铜金只做小面积点缀，≤ 5% |
| 冷暖 | 冷色主体 + 一点暖色点缀，或反过来。不许糊成灰 |

**色彩翻车清单**：紫压到发黑、全身同深色、荧光色大面积、全身金、上下装明度完全一样。

## 四、闸门 3 · 廓形与剪裁

| 项 | 要求 | 为什么 |
|---|---|---|
| 腰线 | **必须明确**（腰带 / 收腰 / 高腰） | 没腰线＝一块布 |
| 比例 | **上短下长**：上衣不盖过胯 | 年轻利落的根 |
| 外层长度 | 长物只能是半透纱 / 披挂 / 后裾；**禁厚重长袍、厚披风** | 大袍压死廓形 |
| 剪裁 | 肩线、袖型、裤型可命名 | 说不清就是糊 |
| 露肤 | **只走一处**（腰 / 肩颈 / 腿，最多两处） | 三处全露＝廉价 |
| 胸衣 | 内层必须是**完整上衣**，**禁内衣外穿感** | 「护胸背心」会被画成胸罩外穿 |

### 层次（与 SKILL.md 强制清单同步）

三层可辨 + 三种材质 + 三处边缘露出 + 配饰密度（上身 ≥3 / 腰 ≥2 / 腿 ≥1）。三层必须是**穿的关系**，不是三件并排挂着。

---

## 五、闸门 4 · 丰富度

| 项 | 要求 |
|---|---|
| 配饰件数 | 6–8 件（少于 6＝空） |
| 分区 | 上身 / 腰部 / 腿部 / 手部都要有东西 |
| 母题 | 一个符号重复 ≥3 处 |
| 功能件 | ≥2 件是「看起来能用的」 |
| 可放大 | 每件单独放大后依然有结构、有材质、有光 |

---

## 六、闸门 5 · 精度

至少这 4 处，放大到 1:1 依然站得住：

1. **眼睛**——虹膜分层、高光、睫毛根根、内眼角
2. **发丝**——分层、有透光、发梢不糊成块
3. **金属件**——哑光底 + 硬高光 + 少量划痕旧化，边缘有厚度
4. **织物**——能看出是什么布（针织颗粒 / 机能布斜纹 / 纱的通透 / 皮革折痕）

加分项：缝线拉链扣眼可见、手部五指结构准确不穿模。

### 脸部检查点（分档验，A 档默认）

**A 档 · 2.5D**：脸不塌不糊；赛璐璐阴影分色干净（交界利落、阴影不脏）；发丝分组一眼数得清；布料与金属有材质区分。四条两条不过＝A 尾缀没吃进去。

**B 档 · 3D**：①眼窝有凹陷（靠结构不是眼影）②鼻梁有真实明暗转折 ③皮肤极细毛孔不油亮。三条缺两条＝B 尾缀没吃进去。

**两档对冲**：半写实容易画平画萌；3D 容易推向成熟偏冷。要「忧郁但好看、带肉感」时补：颧骨略软下巴圆滑、唇色极淡但边缘柔有微水光、眼型细长内眼角微低。

## 七、闸门 6 · 武器 / 道具

| 项 | 要求 |
|---|---|
| 可拆解 | ≥3 段可命名（刃 / 护手 / 握柄 / 能量核 / 铭文） |
| 与属性同源 | 能力要长在武器上 |
| 握持 | 手与柄贴合、不穿模、能说清正握反握 |
| 比例 | 长刀约身高 0.55–0.7，短刃 0.3–0.4 |
| 与服装统一 | 金属色/发光色复用服装辅色或点缀色 |

---

## 八、闸门 7 · 版式（底线）

- 主视觉宽 ≥ 40%、高 ≥ 版面 55%，全版最大。
- 图格只靠 1px 边 + 3px 缝分区，不加投影、不圆角。
- 属性表低对比；每区块挂编号块 + 中文标题 + 英文小字。
- 信息分区 6–9 个。
- **页面底色 = 图格底色 = 主图背景色**，不一致就露方块边。
- 主视觉必须有地面与接触影，背景无颗粒无雾。

## 九、年轻感 vs 老气感

用户原话：「就像年轻人和老年人的区别」。

| 维度 | 年轻（对） | 老气（错） |
|---|---|---|
| 明度 | 亮、浅、透气 | 暗、沉、发黑 |
| 廓形 | 上短下长、腰线利落 | 长袍、披风、拖地 |
| 材质 | 哑光布＋半透纱＋少量金属 | 全厚呢、全皮革、堆金 |
| 妆 | 裸妆、素、干净 | 浓妆、艳唇、亮片 |
| 配饰 | 少而精 | 多而杂、堆成杂货铺 |
| 露肤 | 一处，节制 | 三处全露或一点不露 |
| 元素 | 一个母题贯穿 | 各说各话 |

## 十二、五张对标模板提炼的锚点

| 模板 | 学到什么 |
|---|---|
| 颜歌·霜刃骑士 | 脸极干净（裸妆、几乎无腮红）；配色三色；高腰短裤＋长腿套＋厚底靴；薄纱披挂半透不压身 |
| 云行锦途 | 主色白+浅蓝；机能束具短上衣＋工装裤；厚底机能靴；配色卡与结构图并列；纹样当母题 |
| 紫黑机能（男） | 低饱和紫灰调；脸冷白清透；T恤＋卫衣＋夹克层次；配饰 8 件各有特写 |
| 星河幻音 | 紫蓝＋星形母题重复；短上衣露腰一处；多层短裙＋厚底鞋 |
| 月沐晞 | 新中式轻机械；脸干净带笑意有虎牙；分区＝多角度/头部/服装/配饰/表情 |

五张的共同点：**脸素、色亮、衣短、件精、细节能放大。**

## 十三、交付前验收

- [ ] 脸是裸妆：唇浅、无眼影、腮红淡（≤30%）
- [ ] 脸不凶、不妖、不男性化，有胶原感
- [ ] 背景明度 ≥90%，深色面积 ≤40%
- [ ] 主色 60 / 辅色 30 / 点缀 10，颜色 ≤5 个
- [ ] 有明确腰线，上短下长，无厚重长袍
- [ ] 内层是完整上衣，无内衣外穿感
- [ ] 三层可辨（穿的关系）、三材质、三处边缘露出
- [ ] 配饰 6–8 件，四区分布，母题 ≥3 处，功能件 ≥2
- [ ] 4 处细节（眼/发/金属/织物）可放大不糊
- [ ] 武器 ≥3 段可拆解，握持正确，与属性同源
- [ ] 版式：主视觉 ≥40%、图格 1px 边、属性表低对比
- [ ] 已挂**一条**风格尾缀（默认 A·2.5D）＋「统一负面词库」
- [ ] **主视觉地面存在、背景无颗粒**（V5 新增）
