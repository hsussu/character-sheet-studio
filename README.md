# 角色设定集工坊（character-sheet-studio）

一套给 AI 用的角色设定集生成流程skill。从参考图开工，先把版式与风格拆清，再访谈补齐角色信息，然后一个区块一张地分步生成，最后拼成整版设定集。

## 核心流程

1. **阶段 0** 解析参考图：认版式家族、数元素、抽风格基准
2. **阶段 1** 定模板：选 A 新中式 / B 都市清冷 / C 哥特暗黑
3. **阶段 2** 访谈：名字、身份、世界观、性格、标志物类别（配饰 / 道具 / 武器，必选其一）
4. **阶段 3** 锁定卡：五维度（内容 / 风格 / 色调 / 构图 / 细节）写成可画的具体值
5. **阶段 4** 分步生成：主视觉 → 三视图 → 细节组 → 表情组 → 可选区块
6. **阶段 5** HTML 拼版，交付整版 PNG

## 五条铁律

- 主视觉必**全身**，半身只能当附加区块
- 多角度立绘必锁**正 / 侧 / 背**三个方向
- 头部与服装细节必出
- 配饰 / 道具 / 武器归为一类，每次必问选哪一类
- 表情与姿态必出

除锁死项外，其余区块选 **3–6 个**，可随时追加。整张设定集元素总数不超过 12，超了就拆张。
