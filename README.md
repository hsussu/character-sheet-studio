# 角色设定集工坊 V2（character-sheet-studio）

一套给 AI 用的角色设定集 / 角色资产图生成技能。给一张设定图或几句描述，先拆风格，再补信息，然后一个区块一张地生成，最后用 HTML 真字体拼版，导出 PNG。

> 当前版本：**V2**（2026-11-27）。第一版对应旧的 skill-1，已在同一目录**原地覆盖**，不另存旧版。

## V2 相比第一版改了什么

| 项 | 第一版 | V2 |
|---|---|---|
| 交付形态 | 只有设定集画册 | 设定集（默认）+ **资产图**（A-pose / 透明底 / 分块 PNG） |
| 可选区块 | 3–6，口径含糊 | 3–6，**默认 5**；减到 3 时保留头部 + 服装 + 标志物 |
| 确认次数 | 多轮逐步点头 | **只确认 2 次**（定档后、地基后） |
| 必问项 | 多轮访谈 | 只必问一句：标志物用 **配饰 / 道具 / 武器** 哪一类 |
| 工具链 | 混入 MJ / SDXL 参数 | 全部改为 `image_gen` / `image_edit` + 百分比坐标 |
| 三视图坐标 | 不统一 | `2–32 / 34–64 / 66–96`，等距、脚底同线 |
| 图上文字 | 直接写中文 | 图上**零文字**，全部 HTML 真字体渲染 |
| 一致性校验 | 「同一人」是空话 | 四项硬锚点：发型轮廓、腰带位置、道具手、鞋型 |

## 铁律

1. 必出主视觉**正面全身** 1 张 + 正 / 侧 / 背**三视图** 3 格
2. 其余区块 3–6 个，默认 5；减到 3 时保留头部 + 服装 + 标志物
3. 单次生成请求 ≤ 6 格、≤ 12 个主体物件（HTML 拼版不受此限）
4. 坐标用百分比，背景用色值
5. 只确认两次；用户说「先出一张看看」就跳过确认直接出

## 流程

```text
阶段 0 解析参考图 → 阶段 1 定档（唯一必问 + 确认①）
→ 阶段 2 锁定卡（告知不停）→ 阶段 3 主视觉 + 三视图（确认②）
→ 阶段 4 其余区块一次出齐 → 阶段 5 HTML 排版 → 导出 PNG
```

生成顺序原则：**被后面引用越多的图越先出**。主视觉定脸、三视图定结构。

## 区块与画幅

| 区块 | 画幅 | 格数 |
|---|---|---|
| 主视觉（必出） | 3:4 | 1 张全身 |
| 三视图（必出） | 16:9 | 3 格 |
| 头部细节 | 3:2 | 1–5（默认 4） |
| 服装细节（含鞋） | 4:3 | 1–5（默认 4） |
| 标志物组 | 3:2 | 3–5（默认 5） |
| 表情 | 3:2 | 3–6（默认 6） |
| 姿态 | 3:4 | 2–5（默认 4） |
| 色卡 + 材质 | 3:2 | 色卡 4–8 / 材质 3–6 |

## 怎么用

把整个目录放进技能目录（`<skill_root>/character-sheet-studio/`），入口是 `SKILL.md`。然后在对话里发一张设定图，说「照这个风格做个角色设定集」或「出资产图，喂 AI 用」即可。
