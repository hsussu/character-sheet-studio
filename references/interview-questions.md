# 角色访谈清单

## 原则

1. **一轮不超过 3 个问题，2 轮封顶**；答完就开工，不再追问。
2. **能从参考图推出来的，绝不再问**。先提取，再问差额。
3. 用户回答抽象时，追问一次落到可画的具体项；仍不明确就按参考图风格推定，并说明依据。
4. 每轮结束时，把已确认项复述成一句话，避免误解累积。
5. **能省则省**：一轮能问完就一轮；用户说「你定」「随便」「快速来一版」，直接给推定版，不再追问。

下面四组是**问题库，不是必答卷**——挑缺的那几条问，不缺就跳过。实际最多问两轮、每轮 3 条。

## 第一轮 · 骨架

```text
1. 角色叫什么名字？有没有英文名或称号？
2. 性别、大概年龄？
3. 什么身份？（侠客/学生/佣兵/医者/公主/机械师…）
4. 什么世界观？（古代武侠 / 现代都市 / 科幻 / 校园 / 蒸汽朋克…）
5. 整体基调？（正剧严肃 / 轻喜日常 / 暗黑 / 热血）
```

## 第二轮 · 外观

```text
1. 脸型和年龄感？（鹅蛋脸显小 / 骨相明显显成熟 / 圆脸显幼…）
2. 眉眼是什么形状？（杏眼、丹凤、下垂眼、上挑…）眼睛什么颜色？
3. 发型：长度、直或卷、刘海、有没有扎起来或编发？
4. 身形比例？（纤细修长 / 匀称 / 娇小 / 高挑，大致身高）
5. 有没有记忆点？（虎牙、泪痣、呆毛、异色瞳、耳饰、疤痕）
```

## 第三轮 · 服装与道具

```text
1. 主色是哪一两个？辅色？
2. 服装风格？（新中式 / 汉服 / 机能风 / 学院 / 工装 / 礼服）
3. 上装结构：领型、袖型、长短、开衩？
4. 下装 + 鞋：裤子还是裙、什么鞋型？
5. **标志物属于哪一类：配饰 / 道具 / 武器？（三选一，必答，不许跳过）**
   - 配饰：耳饰、项链、墨镜、手袋、腰带、戒指
   - 道具：随身器物、工具、机关、书本、乐器、科技小件
   - 武器：剑、匕首、枪械、法杖、弓
```

## 第四轮 · 表演与呈现

```text
1. 用三个词形容性格？
2. 需要哪些表情？（默认微笑 / 眨眼 / 开心 / 俏皮 / 清冷 / 疑惑 / 生气 / 惊讶…）
3. 要不要加色卡/材质板，或属性文字块？（两项都是低成本高效果，可后期排版）
4. 这套设定集主要用来干什么？（自己收藏 / 做视频参考 / 画漫画 / 喂给 AI 长期用）
5. 除锁死的全身主视觉和正/侧/背三视图，还要哪些区块？（头部细节 / 服装细节 / 标志物 / 表情 / 姿态 / 色卡材质，3–6 个，默认 5 个，可随时追加）
```

第 4 题（用途）决定交付规格：喂 AI 长期用 → 必须有严格的三视图和锁定卡；自己收藏 → 侧重主视觉美感。

## 从参考图可直接提取的项

看到参考图先填这些，不要问：

| 项 | 从图里怎么看 |
|---|---|
| 服装款式与结构 | 直接看，写清楚领型/袖型/腰线/开衩 |
| 主色与辅色 | 直接取色，用颜色名 + 明度描述 |
| 道具 | 图里出现的都列出来 |
| 发型轮廓 | 长度、卷直、刘海、束发方式 |
| 表情范围 | 表情格里有几个就照抄 |
| 版式骨架 | 格子数量与位置 |
| 画风 | 二次元半写实 / 平涂 / 3D |

真正必答的只有两样：**名字**、**标志物类别（配饰/道具/武器）**（且仅当区块组合含标志物组时问）。身份、世界观、性格、脸型、配色都能由你推定——推定后补一句「我按 X 定的，理由是 Y」，用户不满意再改。有参考图时加问一句「哪些地方要改」。区块组合默认 5 个、3–6 可调，用户不表态就按默认走。

## 追问话术

| 用户说 | 追问成 |
|---|---|
| 「好看就行」 | 「那我按参考图的清冷仙气路线走，脸用鹅蛋脸、色调保持浅黄+雾蓝，行吗？」 |
| 「随便」 | 自己定，然后写「我定了 X，理由是 Y，不满意随时改」 |
| 「你看着办」 | 同上，但必须先给参考图解析结论，让用户看到判断依据 |
| 「跟她一样」 | 「完全照搬，还是换配色/换发型？照搬的话只需要给个名字」 |
| 「先出一张看看」 | 直接进阶段 3 给锁定卡草案 + 立刻出第 1 步主视觉，别拖流程 |
| 「配饰道具武器我都想要」 | 「只能选一类做主组，另一类并进服装细节，或另行开组但总区块上限 6」 |
| 「还要再加两个」 | 「现在是 X 个，加到 Y 个，上限 6；超了每格会被压小、细节全糊」 |

## 锁定卡填写要求

五个字段都必须有**可画的具象值**，禁止出现这些词：

> 好看、气质、特别、独特、高级、有感觉、仙、酷

替换示例：

| 空词 | 改成 |
|---|---|
| 很仙 | 淡鹅黄 + 雾霾蓝，低饱和高明度，长袍垂坠，发丝有微风感 |
| 很酷 | 黑银配色，哑光皮革 + 金属扣件，眼尾上挑，站姿重心后压 |
| 有气质 | 修长身形，肩线下沉，颈线拉长，视线不直视镜头 |
