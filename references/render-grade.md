# 渲染档位判定（2.5D / 3D 半写实 / CG 级 / BJD）

> 用户说「照这个风格做」「这就是我要的建模」「是不是 BJD 那种」时，先按本表定位档位，再决定走哪套提示词。
> **判档错了，后面 20 张全废。**

---

## 一、四档一眼分辨

| 档 | 一眼特征 | 典型来源 | 工坊里怎么走 |
|---|---|---|---|
| **A · 2.5D 平涂** | 赛璐璐分色、阴影边界利落、色彩块面干净、发丝分组成片 | 手游立绘、国创动画截图 | 默认档，风格尾缀 A |
| **B · 3D 半写实** | 有体积、有材质、阴影连续，但材质"轻"（发丝成块、织物简化） | AI 视频直出（即梦/可灵）、游戏建模参考 | 风格尾缀 B |
| **B+ · CG 级** | 皮肤有次表面散射、发丝成束透光、布料有模拟褶皱、电影级体积光 | 游戏 CG 预告、国创动画电影、精修 AI 片 | 风格尾缀 B + 本档三条判据 |
| **C · BJD 工艺感** | 树脂哑光皮肤、玻璃球眼、粘贴假睫毛、外露球关节 | 球关节人偶摄影、娃圈图 | **只有用户点名"BJD / 球关节 / 树脂娃"才做** |

**默认永远不是 C。** 用户拿 CG 图说「是不是 BJD 那种」，答案是「不是」，并按 B+ 走。

## 二、BJD 与 CG 的硬判据（拿这张表逐项对照，不靠感觉）

| 维度 | C · BJD | B+ · CG 级 |
|---|---|---|
| 皮肤 | 哑光树脂，无毛孔、无透光，能看出"塑料/树脂" | 次表面散射：耳廓、鼻翼、下颌边缘逆光透红；T 区高光柔 |
| 眼睛 | 玻璃球眼，整颗高反光，虹膜像平面贴纸 | 角膜层独立高光 2 点；虹膜 3 层（外环/内环/瞳孔） |
| 睫毛 | 粘贴根状假睫毛，排布整齐、边缘硬 | 毛发渲染，末端细、有透光 |
| 关节 | 肩肘腕髋膝踝外露球关节 | 无外露关节，体块连续 |
| 头发 | 雕刻式假发块，边缘片状、有接缝 | 体积发束，每束 3–8 根，束间有空隙，发梢透光 |
| 布料 | 硬挺，褶皱是雕出来的，无垂坠 | 有布料模拟：褶皱有体积、纱有透光、缎有方向性反光 |
| 比例 | 头大四肢细、关节分节，偏工艺品 | 7.5–8 头身（姐姐向）或 6.5–7 头身（可爱向），解剖连续 |
| 光 | 棚拍硬光、背景纯色 | 电影光：侧逆光、体积光、丁达尔、暗部留 15–20% |

**一句话**：BJD 是「做得像人的工艺品」，CG 是「做得像画的人」。

## 三、B+ 档三条硬判据（出图后逐条验，缺两条重出）

| # | 判据 | 不达标的样子 |
|---|---|---|
| 1 | **皮肤有透光**：耳廓/鼻翼逆光处能看到血色透出，不是一层死皮 | 塑料感、蜡像感、整脸一个色阶 |
| 2 | **眼睛有角膜反光 + 虹膜分层**：至少 2 个高光点，虹膜能看出深浅环 | 一整颗玻璃球、或一坨纯色圆片 |
| 3 | **发丝成束且有透光**：束间有空隙，发梢有亮边 | 一整块头发、边缘成锯齿片状 |

三条缺两条 = 只是 B 档，不是 B+，重写提示词再出。

## 四、B+ 档提示词三件套（挂在内容段末尾，不替换风格尾缀）

```text
皮肤有次表面散射（耳廓/鼻翼/下颌边缘逆光透红），T区高光柔和、有细微皮肤起伏；
眼睛有角膜层双高光（左上大而软、右下小而亮），虹膜三层（深色外环/浅色内环/黑瞳孔）；
发丝成束（每束3-8根、束间有空隙）、发梢逆光透亮、沿发流方向有各向异性条状高光；
布料有模拟褶皱与垂坠、纱有透光；金属哑光底+硬高光+少量旧化；
电影级侧逆光，轮廓有一圈亮边，暗部保留15-20%亮度，空气中少量体积光/尘。
```

**负面词追加（B+ 档专用）**：

```text
不要树脂塑料皮肤、不要玻璃球眼、不要粘贴假睫毛、不要外露球关节、不要雕刻式假发块、不要布料硬挺无褶皱、不要棚拍硬光、不要纯色平底背景
```

## 五、什么时候该切到 C 档（BJD）

只有这三种情况：
1. 用户明确说「BJD / 球关节人偶 / 树脂娃 / 娃圈风格」
2. 参考图本身就是娃圈摄影（能看到球关节或树脂反光）
3. 做「人偶角色」设定（世界观里就是人偶/机械偶）

**切到 C 档时必做的三件事**：把球关节画出来（肩/肘/腕/髋/膝至少露出 2 处）、皮肤转哑光树脂、眼睛转玻璃球。否则做了个 CG 脸挂个「BJD」名，两头不靠。
