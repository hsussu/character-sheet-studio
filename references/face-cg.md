# CG 级脸部参数表（Face Spec · B+ 档）

> 用途：一次把脸做对。脸崩了后面所有图全废。
> 用法：把本表 §2 的数值直接抄进提示词内容段；用 §5 的「锁脸流程」保证后续所有图同一张脸。

---

## 一、先定三件事（顺序不能反）

| # | 定什么 | 怎么定 |
|---|---|---|
| 1 | **头身比** | 姐姐向 7.5–8 / 少女向 7–7.5 / 可爱向 6.5–7。定了就不许在后续图里变 |
| 2 | **眼型长宽比** | 姐姐向 1.9:1（细长）/ 少女向 1.6:1 / 可爱向 1.3:1（圆）。这是"气质"的总开关 |
| 3 | **眼位高度** | 眼中线在头部 1/2 处或略上。**眼位低 = 娃娃脸**，别手滑画低 |

## 二、参数表（可直接抄）

### 2.1 骨相与比例

| 项 | 数值 | 说明 |
|---|---|---|
| 面宽 : 脸长 | 1 : 1.35 | 小鹅蛋，不要瓜子、不要方 |
| 下颌 | 收窄但**保留软组织**，不切角 | 切角 = 男相 |
| 下巴 | 圆润、不过尖 | 过尖 = 蛇精脸 |
| 眼距 | 1.05 个眼宽 | 小于 1 显凶，大于 1.2 显外星 |
| 眼裂长宽比 | 1.9 : 1（姐姐向） | 见 §1 |
| 鼻长 | 脸长 1/4 | 鼻根起点在两眼连线略上 |
| 唇宽 | 脸宽 1/3 | 上下唇厚比 1 : 1.15 |
| 人中 | 短（画面上约 8–10px 比例） | 人中长 = 显老 |
| 耳 | 上缘与眉毛齐、下缘与鼻底齐 | 位置错了整脸崩 |

### 2.2 眼（最吃细节，三条必写）

1. **上眼睑有厚度**：双眼皮线距睫毛根 2–3mm，是两条线不是一条
2. **虹膜三层**：深色外环 → 浅色内环（琥珀/灰绿）→ 黑瞳孔；虹膜占眼裂高度约 70%
3. **角膜双高光**：左上（面积大、边缘软，是主光）、右下（小、更亮，是环境光）

补充：眼尾平不上挑；内眼角略低、有泪阜一点红；下眼睑有卧蚕微光（不是阴影）。

### 2.3 鼻 / 唇

- 鼻：鼻梁细窄、鼻根低平起步、鼻背到鼻头有明暗转折、鼻头圆润一点高光、**鼻孔不外露**
- 唇：唇峰清晰但不锐、唇色淡粉、边缘柔、下唇略厚、有一点**水光（specular 而非 gloss）**

### 2.4 皮肤（CG 感的命门）

| 项 | 要求 |
|---|---|
| 次表面散射 | 三处可见：耳廓、鼻翼侧、下颌边缘（逆光时透红） |
| 高光 | T 区高光弱而柔，面积小 |
| 血色 | 颧骨淡红一小块（≤面颊 1/3），不是腮红块 |
| 质感 | 毛孔不可见，但有细微起伏；**不油亮、不塑料** |
| 暗部 | 保留 15–20% 亮度，不死黑 |

### 2.5 发丝

- 成束：每束 3–8 根，束间有空隙（不是一整片）
- 刘海：2–3 缕不对称，最长一缕过眉
- 发梢：逆光透亮，末端 1–2 根散丝
- 高光：各向异性——沿发流方向一条亮带（不是点状）
- 发色分界：在侧脸 1/3 处，别放正中

## 三、提示词成品段（照抄改数值）

```text
CG级3D半写实，二次元骨相：小鹅蛋脸，面宽脸长比1:1.35，下颌收窄但保留软组织，下巴圆润；
眼距1.05眼宽，眼裂长宽比1.9:1的细长眼，眼尾平不上挑，内眼角略低有泪阜微红；
虹膜三层（深棕外环/浅琥珀内环/黑瞳孔），虹膜占眼裂高度70%，角膜双高光（左上大而软、右下小而亮）；
上眼睑有厚度，双眼皮线距睫毛根2-3mm；鼻梁细窄鼻根低平、鼻背鼻头两段转折、鼻头圆润微高光、鼻孔不外露；
唇宽1/3脸宽，下唇略厚，唇色淡粉边缘柔、有一点水光；皮肤有次表面散射（耳廓/鼻翼/下颌透红），
颧骨淡红，毛孔不可见但有细微起伏，T区高光柔；发丝成束3-8根一束、束间有空隙、发梢透光、各向异性条状高光。
```

负面词追加：

```text
不要塑料树脂皮肤、不要玻璃球眼、不要粘贴假睫毛、不要外露球关节、不要雕刻式假发块、不要圆眼娃娃脸、不要平涂、不要瓜子脸尖下巴、不要鼻孔外露、不要油光
```

## 四、脸型 vs 气质速查

| 想要 | 眼裂比 | 眼尾 | 唇 | 脸 | 头身 |
|---|---|---|---|---|---|
| 清冷姐姐（守灯人型） | 1.9:1 | 平 | 薄、淡 | 小鹅蛋 | 7.5–8 |
| 温柔少女 | 1.6:1 | 微下 | 略厚、粉 | 鹅蛋 | 7–7.5 |
| 俏皮可爱 | 1.4:1 | 微上 | 圆、有虎牙 | 圆脸 | 6.5–7 |
| 非人 / 人偶 | 1.2:1 | 平 | 小、无血色 | 圆 | 6–7 |

## 五、锁脸流程（一次做对，后面全靠它）

1. **生成 6 张**：同一段提示词，只改随机种子，挑一张「三判据全过」的（见 render-grade.md §3）
2. **存为 `角色名-脸-定稿.png`**：这张是全套图的锚点，不许再改
3. **后续每张图**：`image_edit` 传「脸定稿 + 同区块上一版」两张参考，一次不超过 2 张（堆满 10 张会照抄构图）
4. **每张出图后验四项**：发型轮廓 / 眼型长宽比 / 唇厚比 / 发色分界位置。错一项只重出那一张
5. **禁止**：靠文字说「同一个人」——一定变脸

## 六、脸部翻车对照表

| 症状 | 原因 | 修法 |
|---|---|---|
| 脸像另一个人 | 只靠文字、没用参考图 | 走 §5 锁脸流程 |
| 娃娃脸、不够"姐姐" | 眼裂太圆 + 眼位太低 | 眼裂改 1.9:1，眼位提到 1/2 或略上 |
| 脸显老 | 人中长 / 有法令纹 / 颧下阴影 | 缩人中、加胶原感、去颧下阴影 |
| 塑料感 | 没写 SSS、皮肤太亮 | 补 §2.4 三处透光 + 降高光面积 |
| 眼像贴纸 | 没有眼窝结构、虹膜单层 | 补眼窝凹陷 + 虹膜三层 + 双高光 |
| 头发成块 | 没写「成束 3–8 根」 | 补发束与束间空隙 |
| 男相 | 下颌切角 / 眉粗 / 唇薄 | 下颌改圆、眉细化、唇加厚 |
| 一只眼两个瞳孔 | 微距格给了双眼 | 只画一只眼 + 挂「不要重瞳」负面词 |
