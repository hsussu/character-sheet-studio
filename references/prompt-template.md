# 五维度提示词模板

## 目录

- 一、中文通用骨架
- 二、任务模板（A 主视觉 / B 三视图 / C 表情 / D 细节 / E 头部 / F 服装 / G 标志物 / H 色卡材质）
- 三、执行工具与参考图用法
- 四、风格锚点词库
- 五、常见内容漏项
- 六、风格尾缀全文（A / B）

提示词必须按这五段组织，顺序固定。缺任何一段都会偏：缺内容 → 角色空；缺风格 → 出来像网图；缺色调 → 配色乱；缺构图 → 排版散；缺细节 → 材质假。

**五段之后必须再挂一段「风格尾缀」**：从本文**第六节「风格尾缀全文」**原样复制粘贴，只挂一条。**默认挂 A（二次元半写实 2.5D）**；用户明确点名 3D 半写实 / BJD / ZBrush / UE5 时才换 B。A 与 B 不同时出现。尾缀里的视图句要按图型替换（见 SKILL.md「视图句替换表」）。尾缀只补风格与画质，不替代内容段。

**下文所有「五格」「四件」「六个角度」都是默认值，不是死数。** 格数、件数、角度数按用户需求调，只受一条硬约束：**单次生成请求 ≤ 6 格、≤ 12 个主体物件**（一格放 2 件以内）。HTML 拼版不受此限。用户没指定就用默认。

## 一、中文通用骨架

```text
【内容】<角色本体：脸型+眉眼+发型+年龄气质；上身服装款式与主色；下身；鞋；腰带/配饰；标志道具；表情>
【场景设定与风格参考】<版式类型>，<艺术风格锚点>，<背景材质>
【色调色彩】主色 <色1>、<色2>，辅助 <色3>、<色4>，点缀 <色5>；<明度饱和描述>；<打光方式>
【构图视角】<画幅比例>。<区域1 占 x%> 放 <内容>；<区域2 占 y%> 排 <内容>。<朝向/镜头高度/重心>
【细节补充】<材质质感>、<金属/织物细节>、<清晰度与画质参数>
```

## 二、任务模板

### 模板 A · 主视觉全身（第 1 步必用）

不带任何格子，只画一个人。这是整套的地基，脸和「服装层次」都在这步定死。

```text
【内容】全身人物插画。<性别 / 年龄 / 职业身份 / 性格三词>。<脸型>、<眉眼>、<唇>；<发长+轮廓+刘海+发饰>。
服装三层：内层 <材质+颜色+款>、中层 <材质+颜色+款>、外层 <材质+颜色+款>，边缘露出 <领口叠压 / 袖口翻边 / 裙摆破边 / 腰部绑带>；
腰挂 <配饰>，腿环 <配饰>，鞋 <鞋型+材质>；标志物 主类 <3 件> + 辅类 <2 件>。
表情 <具体情绪，含眉/眼/嘴/虎牙等小动作>。
【场景设定与风格参考】无背景的人物立绘，二次元半写实 2.5D，高端动画工作室角色设计稿。
风格配比：主风格 <A>（占廓形 60%）+ 次风格 <B>（占面料/配件/鞋 30%）+ 点缀 <C>（占反差元素 10%）。
<背景：默认纯色，可按风格换渐变/纸纹/虚化场景>，无文字、无水印。
【色调色彩】主色 <色1>、<色2>，辅助 <色3>、<色4>，点缀 <色5>，中性 <色6>；深浅拉开 ≥2 个明度档；<明度饱和描述>；<打光方式>。
【构图视角】竖幅 <比例>。人物居中略偏<左/右>，<正面微侧 x 度>，<重心压单腿/双脚平分>，<手部动作>，<视线方向>。全身完整入画，头顶与脚下各留 8% 空隙。
【细节补充】<面料名>质感，褶皱柔软有体积感；金属件磨砂底加高光；<特殊材质>。
<风格尾缀·原样粘贴（默认 A；点名 3D 换 B）>
```

**主视觉背景段必写的一句（V5）**：`人物完整站在浅灰无缝影棚地面上，脚底有柔和的接触阴影与轻微地面反光，背景为有光影过渡的浅灰渐变（上暗下亮，跨度约 15 阶），不做颗粒、不做纸纹，四周无雾、无光斑，柔和顶光 + 轻微轮廓光`。

### 模板 B · 三视图（第 2 步）

一张图里三个全身，靠坐标硬隔离。

```text
【内容】<同模板 A 的角色段落，一字不改复制>
【场景设定与风格参考】角色三视图设定稿，二次元半写实，3D 渲染质感。<背景色>纯色背景（可换渐变，三格底色必须一致）。
【色调色彩】<同模板 A>
【构图视角】横版 16:9 或竖版 3:4。三个等高的全身立绘沿水平方向等距排列：2%–32% 正视图、34%–64% 侧视图（<左/右> 90 度）、66%–96% 背视图，四周各留 2% 背景。三者身高一致、脚底对齐同一条水平线，间距 ≥ 4% 纯背景。全部正面平视，无透视变形。
【细节补充】<同模板 A>。三个视角的发型轮廓、腰带结构、道具位置必须完全一致。
```

**一把武器只画一份**：三视图里武器只出现一次（不戴就摆在旁边），不要每格都拿一把。

### 模板 C · 表情组（默认 6 个，可 3–6）

```text
【内容】同一角色的 <n> 个表情头像（默认 6，可 3–6），半身或头部特写。<角色脸/发/耳饰描述原样复制>。<n> 个表情依次为：<表情1>…<表情n>，<每个表情的关键动作：眉/眼/嘴/虎牙>。
【场景设定与风格参考】表情设定表，二次元半写实，3D 渲染质感。<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】横版 3:2。6 个排 2 行 3 列、4 个排 2×2、3 个排 1 行 3 列；每格 ≥ 30% 宽、格间留 ≥ 4% 背景。全部平视、同一焦距、同一头部大小、同一光源方向。
【细节补充】表情跨度要拉开（不能全都像在微笑）；<标志特征> 在每个表情中都要保留。
```

### 模板 D · 细节特写组（默认 4 格，可 2–4）

```text
【内容】角色局部特写 <n> 格（默认 4，可 2–4）：<眼部>、<发型结构>、<服装工艺/纹样>、<标志道具>。
【场景设定与风格参考】细节研究图，微距摄影质感与 3D 渲染结合。<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】4 格用 2×2 四宫格（每格 46%）；3 格用 1 行 3 列、2 格用 1 行 2 列；格间留 ≥ 4% 背景。<每格的镜头距离与角度>。
【细节补充】布料纤维可见、缝线整齐、金属反光有层次、<道具> 的刻度与齿轮清晰可辨。
```

### 模板 E · 头部细节组（1–5 格）

```text
【内容】同一角色的头部细节研究。五格依次为：面部半身、眼部特写、眉眼结构、发型结构、鼻唇与耳饰。
**画面下缘一律切到锁骨即止**：不出现胸部、不出现外套上身、不出现肩以下衣物。
眼部微距格只画一只眼（单虹膜单瞳孔）。
【场景与风格参考】头部细节设定表，<风格锚点>，<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】横版 3:2 或 2:3。<五格的排布：左 45% 大正脸跨满栏高 + 右 55% 2×2>，格间留 ≥ 3% 背景。面部半身平视、眼部与眉眼用微距、发型用侧后 45 度。
【细节补充】睫毛根根分明、虹膜有高光与纹路、唇纹可见、耳饰金属反光。<标志特征> 每格都要保留；必带 1–2 件头部配饰，五格都能看见。
```

少于五格时按优先级砍：**面部半身 > 眼部 > 发型 > 眉眼 > 鼻唇耳**。

### 模板 F · 服装细节组（1–5 格）

服装细节的任务是**证明层次**，不是复拍全身。**默认平铺实物（flat lay），画面里不出现人体**：

```text
【内容】同一套服装的局部工艺研究，5 格平铺实物：① 衣领（内层高领 / 中层领层 / 外层翻领，叠在一起平铺）② 袖口与泡泡袖翻边 ③ 腰部（腰带 + 挂饰 + 腿环单独平放） ④ 面料与蕾丝微距 ⑤ 下摆与鞋（靴/鞋侧放）。
【场景与风格参考】服装细节设定表，商品静物质感，纯浅灰底 + 柔和顶光，画面不出现人体。
【色调色彩】<同模板 A>
【构图视角】横版 2:1，五格等宽横排（各 19%），格间留 ≥ 3% 缝，上下齐平。
【细节补充】缝线针脚整齐、褶皱有体积、刺绣走向清晰、金属扣件有磨砂与高光两层；每一格都要看清「这是第几层、和上下层怎么叠」。
```

**为什么禁人体**：一带人体就必须切断脖子或腿，切口顶在画面边界时就是「一根脖子悬在那」，看着像解剖图。用户明确要求「穿在身上」才切回人体局部，此时上缘切在下巴以下、下缘不低于大腿中段。

**三条禁止**（写进提示词末尾）：禁止正面低角度；禁止展示裙底、腿根等隐私部位；禁止两格用同一个视角。

少于五格时按优先级砍：**领口 > 袖口 > 腰 > 裙摆 > 鞋**。

### 模板 G · 标志物组（3–5 格，可混搭）

**G-0 混搭规则（默认做法）**

硬约束：**同一件道具最多占 2 格（整体 + 1 格局部）；3–5 格里必须出现 ≥3 个不同物件。** 两类之间必须有**共同母题**：

| 主类 | 辅类 | 共同母题怎么定 |
|---|---|---|
| 配饰（发饰/耳饰/颈圈/腰挂） | 武器（短刃/枪） | 同一金属质感与同一符号 |
| 道具（机械小件/随身器物） | 配饰（戒指/手环） | 同一发光色与同一包边工艺 |
| 武器（剑/弓） | 配饰（挂饰/符牌） | 同一纹样与同一配色点缀 |

**反例**：一把刀占「整体 / 刃部 / 柄部」三格，等于全组只有一把刀。

**混搭句式**：

```text
【内容】角色标志物 5 格横排：<物件1>整体 1 格 + <物件2> 1 格 + <物件3> 1 格 + <物件4> 1 格 + <其中任一件>局部特写 1 格。每件单独摆放，不重叠。全部共用 <母题：同色金属/同符号/同发光色>。
```

**G-1 配饰类**：

```text
【内容】角色佩戴的 <n> 件配饰（默认 5，可 3–5）平铺展示：<配饰1>…<配饰n>。<材质与颜色各写清>。
【场景与风格参考】配饰与专属物展示，产品静物摄影质感，<背景色>纯色背景。
【色调色彩】主色 <色1>、<色2>，点缀 <色3>。柔和顶光 + 轻微侧光，金属有清晰高光。
【构图视角】横版 3:2，<n> 件等距横排（5 件各占 18%、4 件各占 22%、3 件各占 30%），间距 ≥ 2.5%。每件单独摆放，不叠不挂，正面或 45 度。
【细节补充】镜面反射干净、链条节距均匀、皮质有毛孔纹理、宝石有内部光。
```

**G-2 道具类**：

```text
【内容】角色随身 <n> 件道具（默认 5，可 3–5）：<道具1>…<道具n>。含材质、磨损痕迹、可动结构。
【场景与风格参考】道具设定表，概念设计图风格，<背景色>纯色背景。
【构图视角】横版 3:2，<n> 件等距横排，45 度俯视，能看到结构侧面与底面。
【细节补充】齿轮咬合清晰、刻度可读、皮革包边有磨痕、发光件有辉光溢出。
```

**G-3 武器类**：

```text
【内容】角色武器 <武器名>，**最多 2 格**：整体图 1 格（含刃、柄、配饰全貌）+ 1 格局部特写（只能选一处：刃口纹理 或 柄部结构与流苏，二选一）。
【场景与风格参考】武器设定稿，概念设计图风格，<背景色>纯色背景。
【构图视角】2 格用 1 行 2 列（各 46%）或 1 格全宽。整体竖放或斜 45 度，占格高 90%；局部微距贴格顶。
【细节补充】刃口反光成一条亮线、刃身有锻打纹、握柄缠绳有磨损、铭文刻痕锐利。
```

**武器的分量靠「大」和「清」，不靠「多」。** 一把刀给一格大图，比拆成三格小图有说服力。

### 模板 H · 色卡 + 材质板

```text
【内容】A 区：<n> 个圆形色卡（默认 6，可 4–8），横向等距；B 区：<m> 块材质方块（默认 6，可 3–6），2×3 或 1 行排列并带小标签。
【场景与风格参考】配色与材质参考板，极简平面设计风格，<背景色>纯净背景。
【色调色彩】A 区按主色顺序排：<色1> 到 <色n>。
【构图视角】竖版 3:2 上下分区，A 区占上 40%，B 区占下 55%，中间留 5%。
【细节补充】色卡边缘干净、材质方块有真实纹理与微阴影。
```

## 三、执行工具与参考图用法

实际跑的是 `image_gen`（文生图）和 `image_edit`（带参考图编辑），没有 MJ / SDXL 的参数，别写进提示词。

| 场景 | 用哪个 | 怎么做 |
|---|---|---|
| 全新角色、无参考图 | `image_gen` | 锁定卡原样粘进提示词，风格五项照填 |
| 已有角色、必须保脸 | `image_edit` | 参考图传主视觉（同区块再加一张上一版），一次 1–2 张 |
| 参考图数量 | — | 工具最多接 10 张；不要堆满，堆满会照抄构图 |
| 三视图 | `image_edit` | 参考图传主视觉，坐标写死 2–32 / 34–64 / 66–96 |
| 排除干扰 | — | 用正向描述锁定（纯背景、无文字、单个人物），否定词放末尾单独一段 |

**`image_edit` 参数格式（硬要求）**：标准 JSON 对象，`request_list` 数组，每项含 `prompt` / `image_reference_url_list` / `width` / `height` / `image_name`。绝不写成 XML 或伪标签文本。

## 四、风格锚点词库

- 二次元：`anime key visual` / `light novel illustration` / `cel-shaded 2D`
- 半写实：`semi-realistic anime` / `3D render anime style` / `game character render`
- 设定集：`character design sheet` / `model sheet` / `concept art book page` / `animation studio character study`
- 国风：`neo-chinese style` / `guofeng` / `hanfu-inspired silhouette` / `wuxia fantasy`
- 蒸汽朋克：`light steampunk` / `brass and silver hardware` / `clockwork ornament`
- 机能 UI（排版）：`techwear UI` / `game UI presentation` / `HUD frames` / `infographic design`

## 五、常见内容漏项

- 虎牙、呆毛、痣、耳饰、指甲色
- 腰带扣数、袖口宽窄、裤脚处理
- 道具的材质与发光点
- 鞋型（短靴/长靴/厚底）
- 后腰/背面的结构（背面视角没有这个就会空）

## 六、风格尾缀全文（A / B 二选一，默认 A）

规则：凡出图一律以 A 收尾，不许省略、不许换词；只有用户明确说出「3D 半写实 / 高精度 3D / BJD / ZBrush / UE5 / 建模参考」之一，才把 A 整段换成 B。**A 与 B 不同时出现**。

### 风格尾缀 A · 二次元半写实 2.5D（默认）

```text
全身角色资产设定图，二次元半写实2.5D风格，日系游戏角色，同一角色、同一服装、同一配色、同一比例，姿态自然有活人感（重心落在一侧腿、另一侧腿微错开半步、肩线略斜，可一手搭胯或扶剑柄、另一手自然下垂，身体略侧向镜头 15 度，不要僵直正对、不要双臂平张），正面、侧面、背面三视图等大并排，脚底对齐，完整全身含脚，正交视图，无透视畸变，轻线稿配合半写实上色，柔和赛璐璐阴影，渐变高光，轻微写实材质，风格化但准确的人体比例，精致五官，发丝分组清晰，服装褶皱与配饰细节丰富且三视图一致，柔和轮廓光，浅色干净背景，无场景无道具，游戏角色资产参考，2.5D渲染，动漫游戏CG质感，高质量，高精度，细节精致，色彩干净统一
```

### 尾缀里的视图句要按图型替换

「正面、侧面、背面三视图等大并排，脚底对齐，完整全身含脚」这句是给三视图写的，挂到别的图型必须整句换成（替换表在 SKILL.md「视图句替换表」）。

### 背景颗粒预防（上资料卡的图额外追加）

正向：`clean seamless studio backdrop, smooth gradient background, soft contact shadow on floor, cinematic soft lighting, subtle rim light`
负向：`noise, film grain, dirty background, paper texture, jpeg artifacts, rough surface, cluttered background, floating in the air, foggy halo around subject`

`smooth gradient background` 必须与 `soft contact shadow on floor` 同时出现，否则模型给纯平底、人悬空。
