## 一、三张参考图的共同骨架

不管什么风格，成品都是一整版，结构固定：

```text
┌─────────────────────┬──────────────────────────┐
│                     │  多角度立绘（正/侧/背 3格）│
│                     ├──────────────────────────┤
│   主视觉全身（大图）  │  头部细节（1–5 格）        │
│   左 38% 宽          ├──────────────────────────┤
│                     │  服装细节（1–5 格）        │
│                     ├──────────────────────────┤
│                     │  标志物：配饰/道具/武器    │
├─────────────────────┼──────────────────────────┤
│ 属性表 + 关键词      │  表情 / 姿态 / 色卡材质    │
└─────────────────────┴──────────────────────────┘
```

坐标（1024×1536 竖版）：左栏 4%–42%（宽 38%），右栏 46%–96%；上半 6%–62%，下半 66%–94%。

**主视觉必须是全身。** 参考图 3 用的是半身大特写当主视觉，那是因为哥特风要突出妆造；复刻这类版式时必须补一张全身主视觉，半身只能当附加区块，不能替代。

**生成时按区块分开出图，最后用 HTML 拼成一版。** 不要指望模型一次画完整版。

### 共性规律

1. **主视觉一定最大**，占版面 30%–40%，其余全为辅助。
2. **三视图永远正/侧/背**，方向不许改。
3. **头部细节永远拆细**：脸、眼、眉、发、唇/耳，越细越显专业。
4. **标志物组独立成区**，图 1 是道具（机械包+科技管），图 2 是配饰（墨镜+耳链+包+手机），图 3 是配饰（十字架项链）。
5. 高级版还带**色卡 + 材质板**，这两个区块成本低、出效果快。
6. 文字全部后期排版，图里只留位。

## 三、三种风格模板

选模板时看参考图的三个信号：背景明度、主色饱和度、材质复杂度。

### 模板 A · 新中式仙侠（浅色系）

| 项 | 值 |
|---|---|
| 背景 | 米白到浅灰渐变，纸面质感，细金线描边 + 星芒 |
| 主色 | 淡鹅黄 / 雾霾蓝 / 银灰 / 珠光白，点缀青蓝荧光 |
| 材质 | 丝缎、薄棉、哑光银、磨砂金属 |
| 光 | 柔和均匀影棚光，几乎无硬阴影 |
| 风格词 | `neo-chinese style`, `wuxia fantasy`, `light steampunk`, `game concept art` |
| 标志物倾向 | 道具多（机关、器物、科技小件） |

### 模板 B · 都市清冷（黑白灰）

| 项 | 值 |
|---|---|
| 背景 | 冷灰白，无纹理，纯净 |
| 主色 | 雾银灰 / 冷月白 / 烟墨黑 / 雾蓝灰，点缀薄紫 |
| 材质 | 垂坠感面料、真丝、漆皮、细链条、磨砂金属 |
| 光 | 冷调侧光，强反差，人物边缘有冷光轮廓 |
| 风格词 | `editorial fashion illustration`, `minimal cool`, `monochrome`, `high fashion` |
| 标志物倾向 | 配饰多（墨镜、耳链、手袋、手机） |

### 模板 C · 哥特暗黑（重工）

| 项 | 值 |
|---|---|
| 背景 | 深灰到炭黑，带轻微颗粒 |
| 主色 | 银白 / 炭黑 / 冷灰，点缀暗红或冷紫 |
| 材质 | 蕾丝、皮革、金属十字架、水晶、厚底靴 |
| 光 | 单点硬光 + 深阴影，皮肤高光明显 |
| 风格词 | `gothic`, `dark fantasy`, `heavy ornament`, `character concept sheet` |
| 标志物倾向 | 配饰多（十字架、颈链、戒指），也可武器（细剑、匕首） |

## 四、风格继承规则

**不许自己发明风格。** 从参考图提取这五项，原样写进锁定卡：

| 提取项 | 从图里怎么看 |
|---|---|
| 背景明度 | 浅 / 中 / 深，带不带纹理 |
| 主色三色 | 直接取色，写颜色名 + 明度 |
| 装饰元素 | 有没有边框线、星芒、色卡、刻度 |
| 光的性格 | 均匀柔光 / 冷侧光 / 硬单点光 |
| 材质复杂度 | 素面 / 中等 / 重工堆叠 |

这五项定下来，风格就不会跑偏；剩下的才是角色本身。
