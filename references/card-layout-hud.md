# 资料卡版式 · HUD 骨架（V5 默认）

> 来源：2026-11-28 沈清栀资料卡 V7 定稿，用户原话「这才是我要的排版和效果」。
> 单位 CSS px；`device_scale_factor=1.5` → 成品 **2160 × 2577**（比例 0.838，合格区 0.78–0.84）。
> 模板：`assets/card-skeleton-hud.html`（复制整套，只换图与文案）；构建：`scripts/build_card.py`。
> 备选平版（无 UI 描边、无编号块）：`references/card-layout-spec-flat.md` + `assets/card-skeleton-flat.html`。

## 这套骨架的「味」在哪（先理解再动手）

参考卡「凌域·夜栖」的气质来自四件东西，缺一件就掉档：

1. **编号块**：每个栏标题前一枚实心小方块 `01–05`，绿底白字，8px，字距 1，padding 2.5×5。没有它，整套变普通图文。
2. **带刻度端点的细线**：标题文字后面一条 `flex:1` 的 1px 线，右端接 1×5px 竖短刻。模拟 HUD 标尺。
3. **卡片化属性表**：白底 94% 不透明的浮卡，行与行之间 1px 细线，左小字标签 + 右值。
4. **图格细边框**：每格 1px `#D3DCD5` 边 + 3px 缝。图片不裸贴，也不加投影。

## 四、图片裁切口径（V5 修正版）

| 位置 | fit | position | 说明 |
|---|---|---|---|
| 主视觉 | 直出 | — | 整块贴上，mask 四边渐隐；不重新裁人 |
| 三视图 | cover | 50% 50% | 原图 1.78 与格 1.75 几乎吻合 |
| 头部大格 | contain | 50% 50% | 图比格窄时四边加 10px mask，融进格底 |
| 头部 2×2 | contain | 50% 50% | 微距图也 contain，避免切掉眼/唇 |
| 服装 5 格 | cover | 逐格调 | 竖长平铺图必须逐格调 position |
| 配饰 5 格 | cover | 逐格调 | 竖长道具（剑）给护手特写，position ≈ 44% |
| 表情 6 格 | cover | 50% 44% | 保下巴，不要切到两侧头发太多 |

**逐格 position 的经验值**（沈清栀卡实测，五格竖构图素材）：

```css
.cost>.fig:nth-child(3) img{object-position:50% 50%}   /* 腰部：腰带+挂饰+腿环 */
.cost>.fig:nth-child(5) img{object-position:50% 92%}   /* 下摆：裙摆+袜+鞋都要露 */
.acc>.fig:nth-child(5)  img{object-position:50% 44%}   /* 长剑：给护手+羽翼特写 */
```

竖长素材（比例 <0.3）cover 进近方形格时，`contain` 会把物件缩成一条线，`cover` 才能看清；宁可只给局部，也不给一根线。

## 七、版式铁律（违反任意一条就重排）

1. **页面底色 = 图格底色**，两者不同就出现表格块感，这是用户反复挑的第一号问题。
2. **图格必须 1px 边 + 3px 缝**；不许图片裸贴、不许加投影、不许圆角。
3. 每栏被格子填满，标签数 = 格数；不许留空格。
4. 属性表 ≤8 行、世界观 ≤4 行、关键词 ≤5 个，超了砍。
5. 星芒 ≤3 枚且都在空白区，不许压标题、不许压图。
6. 右栏总高与左栏齐平，署名条吸底；页脚最后一行落到页面底部 20px 内。
7. 编号块 `01–05` 一个不许漏；漏了整套掉档。
8. 全卡零图片内文字，文字一律 HTML 渲染。
