# 实战校准笔记（Field Notes · 从 17 轮拉锯里提炼的可迁移规则）

> 来源：一个角色从 0 到资料卡定稿，主视觉改了 17 版、区块改了 9 版、排版改了 7 版。
> 下面每一条都是**真实被打回**换来的，换角色照样适用。角色专属设定（发色、武器名）不写进来。

## 一、用户怎么提需求，我怎么接

| 用户的行为 | 正确反应 | 错误反应 |
|---|---|---|
| 圈一块区域说「你看这里」 | 只改圈内那一处，其余不动；改完只交这一处 | 顺手把整张重画、别处也优化一遍 |
| 说「换个 XX」（丢来一张参考图） | 只替换那一个元素，保留原姿态、原光、原构图 | 整张重生成，脸和衣服全变 |
| 说「先别急着下一步」 | 停在这一步，只交付当前图 | 抢着出下一区块 |
| 说「这张就是定稿」 | 把它当唯一锚点，后续全部以它为准，不再回退到我「觉得更好」的版本 | 用自己认为更好的旧版覆盖 |
| 自己主动加了一个元素（如挂件、尾巴外露） | **保留**，并按它改设定口径（尾巴缝进身体后只从侧面垂出一小截） | 按原设定逻辑判它与设定冲突而删掉 |
| 说「这个和风格不适配，是我故意加的」 | 立刻撤回该元素，回到上一版 | 坚持这样更符合设定 |
| 说「糊 / 有颗粒 / 悬空 / 灰」 | 这是缺陷描述，不是风格偏好：直接进 `noise-control.md` / `hero-plate.md` 对应分支 | 解释这是纸张质感 |

## 二、容易被误读的词（先问一句，别自作聪明）

| 用户说 | 意思 | 不是 |
|---|---|---|
| 「双持 / 双手武器」 | 一把长剑，双手交叠握 | 两把剑交叉（最大的一次误读，白做 2 版） |
| 「细剑 / 银白」 | 剑身细长、银白为主色 | 金剑、宽刃、镶满宝石 |
| 「不要爪子 / 不要张牙」 | 护手收拢、纵向排列 | 完全去掉护手装饰 |
| 「加个 XX」 | 在现有基础上加一件 | 换一整套 |
| 「简单点」 | 减装饰、减信息行数 | 减层次、减配饰（层次永远不许减） |

## 三、脸的成熟度（幼态是最常见的返工点）

用户判「幼态」的四个信号，出现两个就说明脸做小了：

1. 眼睛又大又圆、虹膜占满眼眶；
2. 脸型偏圆、下巴尖或短、脸颊鼓起（婴儿肥感）；
3. 腮红面积大、位置靠苹果肌中间；
4. 五官排布靠下，额头占比过大。

**改法（一次全给，别一条条试）**：
- 眼睛改**细长半睁下垂眼**，上眼睑压住部分虹膜（倦怠感），外眼角微垂；
- 脸型改**小巧鹅蛋脸**，下巴不尖不幼，颧骨略软但有轮廓；
- 腮红改成**极淡冷调**、位置靠外下方；
- 眉毛极细极浅、平八字微下垂；鼻子只留鼻尖一点阴影；唇小而薄微嘟。

## 四、五种「锚点机制」（保证跨图一致）

1. **定稿图唯一**：用户指认的那一版存成 `角色名-主视觉-定稿.png`，所有后续图都以它为参考图；
2. **改一处交付一处**：每轮只改一个元素，交付后立刻让用户确认；
3. **四项核对**：发型轮廓、腰带位置、道具手（剑在左手还是右手）、鞋型；
4. **设定口径跟着图改**：图先定，设定后写；
5. **禁止自己改良**：用户没提的元素一律不动，哪怕我认为不好看。

## 五、交付节奏

- 先给图，后给一句说明（改了什么、还差什么），不要先写三段分析再给图；
- 一版一文件，命名 `-01`、`-02` 递增，不覆盖上一版；
- 用户验收后才推进下一区块；不验收就停在原地；
- 发现自己上一步做错了，先承认再修，不要解释成「设计选择」。

## 六、开工前的核对清单（铁律 9 的落地，30 秒能做完）

```text
① 上一版定稿长什么样？腰挂是猫还是葫芦？尾巴露不露？
② 剑在哪只手、握法是什么（单手 / 双手交叠）？
③ 腿环在哪条腿、什么颜色，蝴蝶朝哪个方向？
④ 发色分界是左浅右深还是反过来？刘海齐眉还是中分？
⑤ 领口现在是蝴蝶结还是交叉带？胸针还在不在？
⑥ 这一版要改的是哪一处？除此之外还有什么绝对不许动？
```

有一条答不上来，就先去看图，不许开工。

## 七、排版返工的五次，顺序是这样的（照着走省三轮）

1. v1 页面底色 ≠ 主图背景色 → 露方块边；
2. v2 头部大格 `contain` 留边露出格底色 → 格底采样对齐 + 四边 10px mask；
3. v3/v4 背景颗粒 → 后期平滑无效 → **换底**（`hero-plate.md`）；
4. v5 换底后地平面丢失、脚悬空 → 补地面提亮带 + 接触影；
5. v6/v7 用模糊原图当底 → 周围一圈雾 → **程序化造底**。

**结论：底图问题只有一条正解——抠图 + 造底 + 补接地。其余都是绕路。**
