# 五维度提示词模板

## 目录

- 一、中文通用骨架
- 二、任务模板（A 主视觉 / B 三视图 / C 表情 / D 细节 / E 头部 / F 服装 / G 标志物 / H 姿态 / I 色卡材质）
- 三、参数与参考图权重
- 四、风格锚点词库
- 五、常见内容漏项

提示词必须按这五段组织，顺序固定。缺任何一段都会偏：缺内容 → 角色空；缺风格 → 出来像网图；缺色调 → 配色乱；缺构图 → 排版散；缺细节 → 材质假。

## 一、中文通用骨架

```text
【内容】<角色本体：脸型+眉眼+发型+年龄气质；上身服装款式与主色；下身；鞋；腰带/配饰；标志道具；表情>
【场景设定与风格参考】<版式类型>，<艺术风格锚点>，<背景材质>
【色调色彩】主色 <色1>、<色2>，辅助 <色3>、<色4>，点缀 <色5>；<明度饱和描述>；<打光方式>
【构图视角】<画幅比例>。<区域1 占 x%> 放 <内容>；<区域2 占 y%> 排 <内容>。<朝向/镜头高度/重心>
【细节补充】<材质质感>、<金属/织物细节>、<清晰度与画质参数>
```

## 二、任务模板

### 模板 A · 主视觉全身（第 1 步必用）

不带任何格子，只画一个人。这是整套的地基，脸在这步定死。

```text
【内容】全身人物插画。<性别年龄气质>。<脸型>、<眉眼>、<唇>；<发长+轮廓+刘海>。<上身>；<下身>；<鞋>；<腰带配饰>；<标志道具>。表情 <具体情绪>。
【场景设定与风格参考】无背景的人物立绘，二次元半写实，3D 渲染质感，高端动画工作室角色设计稿风格。<背景色>纯色背景，无环境、无道具、无水印。
【色调色彩】主色 <色1>、<色2>，辅助 <色3>，点缀 <色4>。低饱和高明度，柔和均匀影棚光，几乎无硬阴影。
【构图视角】竖幅 <比例>。人物居中略偏<左/右>，<正面微侧 x 度>，<重心压单腿/双脚平分>，<手部动作>，<视线方向>。全身完整入画，头顶与脚下各留 8% 空隙。
【细节补充】<面料名>质感，褶皱柔软有体积感；金属件磨砂底加高光；<特殊材质>。画面锐利通透，8K，细节丰富，无噪点。
```

### 模板 B · 三视图（第 2 步）

一张图里三个全身，靠坐标硬隔离。

```text
【内容】<同模板 A 的角色段落，一字不改复制>
【场景设定与风格参考】角色三视图设定稿，二次元半写实，3D 渲染质感。<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】横版 16:9 或竖版 3:4。三个等高的全身立绘沿水平方向等距排列：2%–30% 正视图、34%–62% 侧视图（<左/右> 90 度）、70%–98% 背视图，四周各留 2% 背景。三者身高一致、脚底对齐同一条水平线，间距 ≥ 4% 纯背景。全部正面平视，无透视变形。
【细节补充】<同模板 A>。三个视角的发型轮廓、腰带结构、道具位置必须完全一致。
```

### 模板 C · 表情组（第 4 步）

```text
【内容】同一角色的六个表情头像，半身或头部特写。<角色脸/发/耳饰描述原样复制>。六个表情依次为：<表情1>、<表情2>、<表情3>、<表情4>、<表情5>、<表情6>，<每个表情的关键动作：眉/眼/嘴/虎牙>。
【场景设定与风格参考】表情设定表，二次元半写实，3D 渲染质感。<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】横版 3:2。六个头像排成 2 行 3 列，每格占 30%×45%，格间留 ≥ 4% 背景。全部平视、同一焦距、同一头部大小、同一光源方向。
【细节补充】表情跨度要拉开（不能六个都像在微笑）；<标志特征> 在每个表情中都要保留。
```

### 模板 D · 细节特写组

```text
【内容】角色局部特写四格：<眼部>、<发型结构>、<服装工艺/纹样>、<标志道具>。
【场景设定与风格参考】细节研究图，微距摄影质感与 3D 渲染结合。<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】2×2 四宫格，每格宽高各 46%，格间留 4% 背景。<每格的镜头距离与角度>。
【细节补充】布料纤维可见、缝线整齐、金属反光有层次、<道具> 的刻度与齿轮清晰可辨。
```

### 模板 E · 头部细节组（1–5 格）

按参考图拆细，越细越显专业。五格版最完整：

```text
【内容】同一角色的头部细节研究。五格依次为：面部半身、眼部特写、眉眼结构、发型结构、鼻唇与耳饰。
【场景与风格参考】头部细节设定表，<风格锚点>，<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】横版 3:2 或 2:3。<五格的排布：上排 2 大 + 下排 3 小>，格间留 ≥ 3% 背景。面部半身平视、眼部与眉眼用微距、发型用侧后 45 度。
【细节补充】睫毛根根分明、虹膜有高光与纹路、唇纹可见、耳饰金属反光。<标志特征> 每格都要保留。
```

少于五格时按优先级砍：**面部半身 > 眼部 > 发型 > 眉眼 > 鼻唇耳**。

### 模板 F · 服装细节组（1–5 格）

```text
【内容】同一套服装的局部工艺研究，四格：领口结构、袖口与手部、腰部与腰带、面料纹样与质感。
【场景与风格参考】服装细节设定表，<风格锚点>，<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】2×2 四宫格，每格 46%，格间留 4% 背景。领口用正面平视、袖口用 45 度俯视、腰部用正面、面料用微距平铺。
【细节补充】缝线针脚整齐、褶皱有体积、刺绣走向清晰、金属扣件有磨砂与高光两层。
```

可加的第五格：**鞋履**（尤其参考图 2 那种高跟/厚底靴，鞋型是造型关键）。

### 模板 G · 标志物组（3–5 格，按选定的类别写）

**G-1 配饰类**（耳饰、项链、墨镜、手袋、腰带、戒指）：

```text
【内容】角色佩戴的五件配饰平铺展示：<配饰1>、<配饰2>、<配饰3>、<配饰4>、<配饰5>。<材质与颜色各写清>。
【场景与风格参考】配饰与专属物展示，产品静物摄影质感，<背景色>纯色背景。
【色调色彩】主色 <色1>、<色2>，点缀 <色3>。柔和顶光 + 轻微侧光，金属有清晰高光。
【构图视角】横版 3:2，五件物品等距横排，各占 18%，间距 2.5%。每件单独摆放，不叠不挂，正面或 45 度。
【细节补充】镜面反射干净、链条节距均匀、皮质有毛孔纹理、宝石有内部光。
```

**G-2 道具类**（器物、工具、机关、书本、乐器、科技小件）：

```text
【内容】角色随身五件道具：<道具1>、<道具2>、<道具3>、<道具4>、<道具5>。含材质、磨损痕迹、可动结构。
【场景与风格参考】道具设定表，概念设计图风格，<背景色>纯色背景。
【色调色彩】<同 G-1>
【构图视角】横版 3:2，五件等距横排，45 度俯视，能看到结构侧面与底面。
【细节补充】齿轮咬合清晰、刻度可读、皮革包边有磨痕、发光件有辉光溢出。
```

**G-3 武器类**（剑、匕首、枪械、法杖、弓）：

```text
【内容】角色武器 <武器名>，四个角度：整体正面、刃部特写、握柄与配重、纹饰铭文。
【场景与风格参考】武器设定稿，概念设计图风格，<背景色>纯色背景。
【色调色彩】<同 G-1>，金属冷光为主。
【构图视角】2×2 四宫格，每格 46%。整体图竖放、刃部斜 45 度、握柄俯视、纹饰微距。
【细节补充】刃口反光成一条亮线、刃身有锻打纹、握柄缠绳有磨损、铭文刻痕锐利。
```

三类**不要混装**：选了配饰就别塞武器，选了武器就别塞手袋。真需要两类的，另开一组，但总数仍受 6 个区块上限约束。

### 模板 H · 姿态组（推荐 4 格）

```text
【内容】同一角色四个全身姿态：自然站立、侧身回望、屈膝半蹲、前倾探身。同一套服装、同一发型。
【场景与风格参考】姿态研究图，<风格锚点>，<背景色>纯色背景。
【色调色彩】<同模板 A>
【构图视角】竖版 3:4，2×2 四宫格，每格宽高各 46%，格间留 4% 背景。四个姿态各占一格，人物全身完整入画、脚底落在格内底线。每个姿态朝向不同，重心分布各异。五个姿态时改 1 行 5 列或 2 行 3 列，每格相应缩小。
【细节补充】衣褶随动作变化、手部结构清晰、发丝有重量感。
```

### 模板 I · 色卡 + 材质板

```text
【内容】A 区：六个圆形色卡，横向等距；B 区：六块材质方块（<材质1>…<材质6>），2×3 排列并带小标签。
【场景与风格参考】配色与材质参考板，极简平面设计风格，<背景色>纯净背景。
【色调色彩】A 区按主色顺序排：<色1> 到 <色6>。
【构图视角】竖版 3:2 上下分区，A 区占上 40%，B 区占下 55%，中间留 5%。
【细节补充】色卡边缘干净、材质方块有真实纹理与微阴影。
```

## 三、参数与参考图权重

| 平台 | 参数 / 手段 | 数值建议 |
|---|---|---|
| Midjourney | `--ar` | 主视觉 3:4 或 4:5；三视图 16:9；表情组 3:2 |
| Midjourney | `--oref` + `--ow` | 权重范围 **0–400**，默认就是 **400**；锁死身份用 **300–400**，压到 100 以下反而会飘 |
| Midjourney | `--style` | 用 `raw`，减少默认美化，保结构 |
| SDXL / ComfyUI | IP-Adapter | 权重 **0.6–0.8**，超过 0.9 会照抄原图构图 |
| SDXL / ComfyUI | ControlNet | 三视图用 openpose 固定站姿，避免三个姿势乱飞 |
| 即梦 / Seedream | 参考图 | 上传角色图，明确写「保持面部与服装完全一致」 |
| 任意 | negative prompt | `grid lines, text, watermark, logo, blurry, extra limbs, fused bodies, cropped head, duplicate character, messy layout` |

## 四、风格锚点词库

挑一个写进「风格参考」段，比空泛说「好看」有效得多。

- 二次元：`anime key visual` / `light novel illustration` / `cel-shaded 2D`
- 半写实：`semi-realistic anime` / `3D render anime style` / `game character render`
- 设定集：`character design sheet` / `model sheet` / `concept art book page` / `animation studio character study`
- 国风：`neo-chinese style` / `guofeng` / `hanfu-inspired silhouette` / `wuxia fantasy`
- 蒸汽朋克：`light steampunk` / `brass and silver hardware` / `clockwork ornament`

## 五、常见内容漏项

写完检查有没有漏这些，模型最容易吃掉它们：

- 虎牙、呆毛、痣、耳饰、指甲色
- 腰带扣数、袖口宽窄、裤脚处理
- 道具的材质与发光点
- 鞋型（短靴/长靴/厚底）
- 后腰/背面的结构（背面视角没有这个就会空）
