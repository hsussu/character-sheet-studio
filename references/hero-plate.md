# 主视觉底图工程 · 影棚光（V5 核心，三次返工换来的）

> 用户三次否掉的顺序：①原图背景有水彩纸颗粒 → ②抠图重铺均匀渐变，脚「悬空、只剩剑的影子」→ ③用大核模糊原图背景当新底，人物四周糊成一团雾。
> 最终通过的做法（V7）：抠图 + 程序化影棚光背景 + 半透明边缘反解 + 贴轮廓接触影 + 保留地平面亮度关系。
> **一句话原则：底可以造，地平面不能造丢；颗粒不能靠糊，要靠换。**

## 一、什么时候必须走这条路

| 情形 | 做法 |
|---|---|
| 原图背景有颗粒/纸纹/JPEG 噪，放到卡片里放大后能看见 | 走本流程（rembg 换底） |
| 原图背景带真实地面光影（棚拍地台、投影） | 走本流程，且**必须还原地平面亮度关系**（见 §四） |
| 原图背景是纯色且干净 | 不用抠图，直接同色贴（省事且不丢光影） |
| 只是小范围脏点 | 用 `noise-control.md` 的局部平滑，不动背景 |

## 二、五步流程

### 1. 分离人物

```python
from rembg import remove, new_session
sess = new_session("isnet-anime")          # 动漫模型，发丝/薄纱边界比 u2net 干净
alpha = remove(img, session=sess, only_mask=True)
```

模型缓存在 `/home/user/.rembg/models/isnet-anime/isnet-anime.onnx`（176MB，首次自动下载）。
**同时把 alpha 存成 `.npy`**（`alpha.npy`），后面所有重做背景都不用再跑模型。

### 2. 反解半透明边缘（关键，不做就会挂灰）

抠图后，发丝/薄纱这些半透明像素里混着**旧背景色**。直接贴到新背景上，发梢会带一片灰雾——用户说的「糊」有一半是这个。

```python
oldbg = gaussian(img, 45)                       # 旧背景估计（含柔和阴影）
fg = (img - oldbg*(1-a)) / max(a, 0.02)         # 反解前景真色
fg = where(a >= 0.12, clip(fg,0,255), img)      # a 太小的区域不反解，放大噪声
out = bg*(1-a) + fg*a
```

阈值 `0.12` 是实测：低于它反解放大噪点，高于它边缘变干净。

### 3. 程序化影棚光背景（不许用「模糊原图」当背景）

```python
t    = y/H
base = 232 + (t**1.7) * 14          # 上暗下亮：232 → 246，跨度 14 阶
base += gauss(620,700,480,720) * 7  # 主体区一团柔光（顶光/侧光）
base += gauss(490,1540,470,230) * 8 # 地面反光
base += gauss(1080,320,340,430) * 2.5
base -= (vig**2.2) * 4.5            # 极淡暗角，只压 4.5 阶
base += exp(-((y-1400)/32)**2) * 3  # 地平线一道更亮的窄带
```

要点：
- **跨度 14–16 阶**：低于 10 就是「死灰一块布」，高于 20 背景会抢人。
- **暗角 ≤6 阶**：卡片是灰底排版的，暗角一大，四角就跟页面底色打架，出现矩形块。
- 想加「空气感/浮尘」**不要真撒粒子**——用户对噪点极敏感，任何颗粒都会被判成噪点。
- 想加「微弱地面反射」，用竖向镜像 + 8% 不透明度叠在脚下 60px 内，不要整片反光。

### 4. 接地（两层影，缺一层就「悬空」）

```python
# A. 贴轮廓接触影：alpha 下移 8px + 4.5px 模糊 + 0.32 强度 → 只贴在鞋底/裙摆落点
cs = shift_down(a, 8); cs = gaussian(cs, 4.5) * 0.32
# B. 脚下一圈柔投影：椭圆 160×55，模糊 22px，强度 0.18
e  = ellipse(cx, cy, 160, 55, 0.18); e = gaussian(e, 22)
sh = clip(cs + e, 0, 0.52); bg = mix(bg, [116,114,122], sh)
```

`cx, cy` 从 alpha 底缘取：找 `alpha>200` 的最底行 `y_max`，再取它上方 30px 内 `alpha>120` 的 x 范围中心。

**同时保留原图地平面的亮度关系**：如果原图脚下方那块比背景更亮（被光打亮的地面），新底也要在 `y > 0.78H` 区域提亮 8–12 阶，否则均匀渐变会把人抬到空中。

### 5. 上卡时的 CSS 配合

```css
.hero{left:-38px;top:0;width:716px;
  mask-image: linear-gradient(90deg,transparent,#000 60px,#000 calc(100%-58px),transparent),
              linear-gradient(180deg,transparent,#000 54px,#000 calc(100%-15px),transparent);
  mask-composite: intersect}
.info{margin-top:-12px}   /* 属性卡压住地台边缘 */
```

- **底部羽化只给 12–16px**：给 40px 会把地台亮度一起吃掉，脚又悬空。
- **属性卡上抬 10–14px**：形成「卡片压在地面上」的层次。

## 三、验收（必须做，不验收不算完成）

1. 裁 1:1 三处：**鞋跟与地面接触处**、**裙纱落地处**、**剑尖下方**。
2. 看四件事：地面是否平（无颗粒）、投影是否在（不是只有剑的影子）、地面亮度是否高于背景上部、边缘是否没有灰雾圈。
3. 再看 4 个角：与页面底色差值 ≤5 阶，否则露方块边。

## 四、禁止清单（每一条都实际踩过）

| 禁止 | 后果 |
|---|---|
| 抠图后铺**均匀渐变** | 地平面丢失，人物悬空，只剩武器影子 |
| 用**大核（≥40px）模糊原图**当新背景 | 人物四周一圈雾，发丝薄纱糊成一团 |
| 只画一圈椭圆阴影不贴轮廓 | 鞋底没有接触暗部，还是飘 |
| 撒浮尘/加颗粒「营造空气感」 | 被当成噪点，直接打回 |
| 暗角压到 -10 阶以上 | 四角与灰页面对不上，出现矩形 |
| 底部羽化 40px | 地台被吃掉，接地失败 |
